> **适用范围**：「设计之眼」的最终交付提示词**只服务 OpenAI GPT Image 2**（API 名 `gpt-image-2`，即 ChatGPT 内的 ChatGPT Images）。Step 10 与输出格式必须遵守本文件，且不产出任何其他模型的版本。

## 1. 硬参数白名单（A 级）

只有以下参数可用。**写任何表外参数 = 错误输出。**

| 参数 | 取值 | 说明 |
|:--|:--|:--|
| `model` | `gpt-image-2`（新项目默认）/ `gpt-image-1.5`（已验证旧流程）/ `gpt-image-1`（仅遗留） | 官方推荐新构建一律用 `gpt-image-2` |
| `quality` | `low` / `medium` / `high` / `auto`（默认） | 草稿用 low；**密集文字、小字、图例、坐标轴、脚注 → `medium` 或 `high`** |
| `size` | 见 §2 | 只有 `gpt-image-2` 支持任意分辨率 |
| `background` | `transparent` / `opaque` / `auto`（默认） | transparent 目前为 **preview**，必须配 `png` 或 `webp`，jpeg 不支持 |
| `output_format` | `png`（默认）/ `jpeg` / `webp` | jpeg 最快 |
| `output_compression` | 0–100，仅 jpeg/webp | **PNG + 透明背景时必须省略此参数** |
| `n` | 生成数量 | — |
| `moderation` | 审核级别 | — |

### ⛔ 禁用参数（硬性拦截）

| 禁用项 | 原因 |
|:--|:--|
| `hd` | DALL·E 3 参数，gpt-image 系列不存在 |
| `input_fidelity` | **对 `gpt-image-2` 官方明确 Disabled**（模型默认高保真处理，API 不允许修改）。仅 `gpt-image-1.5` / `gpt-image-1` / `gpt-image-1-mini` 可用 |
| `partial_images` / `stream` | 与 `gpt-image-2` 无关（社区反馈不支持） |

## 2. Size 取值与校验（A 级）

`gpt-image-2` 接受任意分辨率，**但必须同时满足 5 条约束**：

1. 最大边 **≤ 3840px**
2. 两条边都必须是 **16 的倍数**
3. 长边 : 短边 **≤ 3:1**
4. 总像素 **≤ 8,294,400**
5. 总像素 **≥ 655,360**

> ⚠️ 超过 2560×1440（3,686,400 像素，即 2K）官方标注为 **experimental**，结果可变性增大。生成前需向用户说明。

**常用值速查（已全部通过校验）**：

| 用途 | 尺寸 | 备注 |
|:--|:--|:--|
| 通用方形 | `1024x1024` | 官方推荐默认 |
| 竖版海报 | `1024x1536` | 标准竖版 |
| 横版海报 / 电商封面 | `1536x1024` | 标准横版 |
| 2K 方形 | `2048x2048` | — |
| 2K 宽屏 / 横幅 | `2560x1440` | **推荐可靠性上限** |
| 4K 横版 | `3840x2160` | 实验性 |
| 4K 竖版 | `2160x3840` | 实验性 |

**电商封面硬规则衔接**：`ecommerce_rules.md` 要求横幅比例 → 映射到 `1536x1024`（安全）或 `2048x1152`（2K），**禁止** `1024x1024`。

## 3. 语言规则（定案，不再分支判断）

**提示词一律用中文书写**，不按画面内容切换语言。三条细分：

| 类别 | 规则 | 示例 |
|:--|:--|:--|
| **结构标签** | 固定英文，不翻译 | `Purpose:` / `Subject:` / `Composition:` / `Palette:` / `Typography:` / `Constraints:` |
| **保留英文的词** | 专业术语原样保留，不译 | 镜头规格 `85mm f/2.8`、`medium format`；材料颜料 `Kodak Portra 400`、`matte gouache`、`cold-press paper`；流派 `Bauhaus`、`Swiss Style`；排版 `kerning`、`leading`、`sans-serif` |
| **用中文写** | 构图、空间关系、色彩、光影、材质描述、情绪、隐喻、排除规则 | "主体占画面 62%，上下边缘被裁切" |

**图内要渲染的文字**（中英文都一样）：进双引号 + 标注"逐字、不增删字符"。

> **为什么固定中文**：OpenAI 官方从未规定提示词语言（Cookbook 全文无相关条款）。第三方实测的"英文略稳"仅约 5–10% 差距，远小于提示词本身的写法质量差异；而固定中文让使用者能自己读懂、修改、校对。术语精确性用中英混写补回，不需要整段切英文。

## 4. 提示词结构（A 级 · 官方顺序）

官方原文核心要求：

> **结构 + 目标**：按一致的顺序编写提示词（**背景/场景 → 主体 → 关键细节 → 限制条件**），并包括**预期用途**（广告、UI 样机、信息图）以设定"模式"和润色程度。对于复杂请求，使用**带有标签的简短分段或换行**，而不是一大段话。

> **提示词格式**：极简提示、描述性段落、类 JSON 结构、指令式提示和基于标签的提示都可以很好地发挥作用……对于生产系统，优先考虑**易于浏览的模板**，而不是巧妙的提示词语法。

> **迭代而非过度堆砌提示词**：长提示词效果可能很好，但如果从一个干净的基础提示词开始，然后通过**单点修改的简短后续指令**进行优化，调试起来会更容易。

### 设计之眼专用分段模板（中文内容 + 英文标签）

```text
Purpose: [交付物类型 + 预期用途] — 设定模式与润色程度，必填
Scene / Background: [环境、背景]
Subject: [主视觉主体，含在画面中的占比与位置]
Composition: [景别、视角、透视、留白、视觉路径]
Style & Medium: [风格、视觉媒介、材质；专业术语保留英文]
Palette: [主色 #XXXXXX ~XX%，辅色 #XXXXXX ~XX%，强调色 #XXXXXX ~XX%]
Typography: [字体族、字号层级、字重、颜色、位置]
Text (EXACT, verbatim，逐字不增删字符): "..." / "..." / "..."
Lighting & Material: [光质、方向、氛围、表面质感]
Constraints:
- 无……
- 无……

参数：model: gpt-image-2 · size: [取值] · quality: [取值] · background: [取值] · output_format: png
```

> **只有 `Purpose` / `Subject` / `Text` / `Constraints` 是必填段**，其余按方案需要增删。宁可少一段，不要凑字数。
> **标签保留英文**（给模型的结构信号），**内容用中文**，**专业术语保留英文**（见 §3 表格）。
> **参数段规则**：「参数：」行必须作为提示词的**最后一段**写在同一代码块内，与提示词一起整体复制，不得单独放在代码块外。标签用中文"参数："，参数名与取值保持英文。size 必须先通过 §2 五条硬约束校验。

## 5. 图内文字渲染（A 级 · GPT Image 2 最强能力，必须用足）

> **图像中的文本**：将字面文本放入**引号**或使用**全大写**，并将排版细节（字体样式、大小、颜色、放置位置）指定为限制条件。对于复杂的词汇（品牌名称、不常见的拼写），**逐个字母拼写**出来以提高字符准确度。对于小文本、密集的信息面板和多字体布局，请使用 `medium` 或 `high` 质量。

**执行清单**：

1. 确切文案放双引号，标签写作 `Text (EXACT, verbatim，逐字不增删字符):`
2. 拼写困难的专名 / 品牌名 → 逐字母拼写（如 `S-H-A-N-G-A-N`）
3. 排版细节写成约束，不是形容：字体族、字号层级、字重、颜色、位置（居中 / 右上 / 底部）
4. 要求只出现一次："该文字在画面中只出现一次，清晰可读"
5. 含小字 / 图例 / 坐标轴 / 脚注 → `quality: high`
6. **中文海报**：中文字面同样进引号，并额外加一条"除指定文案外，画面内不得出现任何英文字符"，防止模型夹带英文装饰字

## 6. 排除规则：⛔ 禁止 `--no` 语法

> **限制条件（要改变什么 vs 要保留什么）**：明确说明排除项和不变项（例如，"无水印"、"无多余文本"、"无徽标/商标"、"保留身份/几何结构/布局/品牌元素"）。对于编辑，使用"**仅更改 X**"+"**保持其他一切不变**"，并在每次迭代时重复需要保留的要素清单以减少漂移。

**`--no` 是 Midjourney 语法，`gpt-image-2` 不识别。** 官方 Cookbook 全文未出现任何 negative prompt 或 `--no` 支持说明。

**正确写法** —— 独立的 `Constraints:` 区块，逐行正面陈述，中文书写：

```text
Constraints:
- 无指定文案之外的任何多余文字
- 无水印、无 logo、无商标
- 无[字面主题元素]
- 无[模板化构图 / 孤立白底商品 / 影棚灯光]
```

**编辑场景**（多轮修改时）：

```text
只修改[X]，其余全部保持不变。
保留[人物身份 / 版式 / 配色 / 字体 / 相机角度 / 构图]。
```

> 官方示例原文为 `Only change [X]. Keep everything else identical.` —— 中英文两种写法模型都能执行，本 skill 统一用中文。

### ⛔ 提示词禁用词总表（生成前自查）

| 禁用 | 来源语法 |
|:--|:--|
| `--no` | Midjourney |
| `(word:1.3)`、`[word]`、`BREAK` | Stable Diffusion 权重语法 |
| `masterpiece`、`best quality`、`8k`、`4k`、`ultra-detailed`、`hyperrealistic`、`trending on artstation` | SD 时代废词，已被现代模型忽略 |
| `hd` | DALL·E 3 参数 |
| 详细的相机物理参数当精确约束 | 官方提示"可能被宽泛地解读"，只用于宏观外观与构图 |

## 7. 其他 A 级要点

**写实激活**：直接写 `photorealistic` 最能激活写实模式；辅助可用 `real photograph`、`taken on a real camera`、`professional photography`、`iPhone photo`。避免"影棚精修""刻意编排"类词汇。

**构图**：指定景别（特写 / 全景 / 俯视）、视角（平视 / 低角度）、光影氛围（柔和漫反射 / 黄金时刻 / 高对比）。布局重要时直接标明位置（"logo 在右上"、"主体居中，左侧留白"）。

**氛围保护**：宽幅、电影感、暗光、雨天、霓虹场景 → 额外补充比例、氛围、色彩细节，否则模型会为表面真实感牺牲氛围。

**人物**：描述比例、身体构图、视线与交互（"全身可见包括双脚"、"视线向下看书而非看镜头"）。

**多图输入**：用索引引用 —— `Image 1: product photo ... Image 2: style reference ...`，并说明如何交互（"将图像 2 的风格应用到图像 1"）。

**透明背景**：`background="transparent"` + `output_format="png"`（或 webp），明确要求孤立主体、无背景风景 / 纯色背板 / 棋盘格 / 多余阴影；PNG 时省略 `output_compression`。

**比例 vs size 参数（电商场景易混淆）**：`size` 参数决定**实际输出像素**（如 1536x1024，必须过 §2 五条约束）；提示词 `Composition:` 段末写**比例文字**（如"横幅 16:9"）作为构图语义提示。**两处必须一致**——电商规则要求的"实际比例"写进提示词，对应像素给 size 参数，不要只写其一。

## 8. ⚠️ 经验级（B 级，非官方保证，可用但不要当规则）

- **hex 色值**：官方未承诺 hex 精确生效。写法上**必须 hex 与文字描述双写**（`deep navy #0E2A47`），不能只给 hex。
- **"as a ..." 模式短语**（`as a magazine cover` / `as an infographic for a slide deck`）：官方只说要声明"预期用途"，具体短语属社区经验。归入 `Purpose:` 段使用。
- **胶片 / 镜头型号**（Kodak Portra 400、85mm）：官方未背书，但也不在禁用表内，作为风格倾向词可用，不要当精确物理约束。
- **关键字符串必须人工复核**：电话、价格、人名、地址 —— 即便 A 级能力也非 100%，生成后必须肉眼核对。
