# 播放页与本地页原型优化记录

## 本次范围
- 只改 `.impeccable/mocks/decision/r4-the-line.html` 与 `l5-living-shelf.html` 两份独立 HTML 原型。
- 不改生产 TSX/CSS，不接入真实库状态；页面中的曲目、计数与频谱仍为演示内容，并在本地页加了醒目标注。

## 主要修改

### r4-the-line 播放页
- 时间地形尺与底部进度条分别按各自元素尺寸换算 seek，避免复用时间尺坐标导致底部拖动定位错误。
- 拖动开始时记录原播放态；pointerup、pointercancel、lostpointercapture 都会恢复正确状态，暂停状态拖动后不再误启动。
- 底部进度条可通过鼠标、触摸和键盘控制；←/→ 快退/快进 5 秒，Home/End 跳首尾；避免与全局快捷键重复处理。
- 歌词词块 click/Enter/Space 直接跳到对应词时间；段落按钮补可读名称与时间提示。
- 明确标出首屏是样例曲目 / DEMO DATA。
- 提高浅色背景上的次要文字对比度。

### l5-living-shelf 本地页
- 标明页面内曲目、数量与扫描结果均为示例数据，降低被误认成真实曲库状态的风险。
- 唱片墙与字母尺在窄窗显示可见横向滚动条；窄窗下收缩副翼封面、保留主唱片和可触达视图按钮。
- 加入唱片封面键盘焦点样式。
- 示例空库计数不再被入场动画错误覆盖回非零值。
- 将馆藏栏标题调整成连续的 heading 层级。
