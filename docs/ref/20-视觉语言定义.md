# 16 · 视觉语言定义（阿飞飞 AFEIFEI）

> 这份文档回答一个问题：**这套界面到底是什么风格，新的东西应该长什么样。**
> 它不列待办（待办在 `docs/19-UI优化清单.md`），只定规则。写于 B1 字号阶梯、C1 红色收敛之后。

---

## 0. 一句话

这套界面的风格是**一张唱片节目单**：纸、墨、一根细线、一个红印章。

不是"暗色玻璃音乐播放器"，也不是"现代化音乐 App"。它像音乐会散场时工作人员递给你的一页节目单——米色纸，黑色铅字，栏目之间一根细线，唯一鲜艳的东西是盖上去的那个红印。

---

## 1. 三条判断依据

判断依据不是形容词，是**已经写进代码、改一下就会被用户察觉**的三件事：

**① 载体是纸。**
底色 `--pr-paper #f3f1ea`（冷米白），页面上覆盖一层极淡的纸纹颗粒（`#rs-grain`，opacity .12 / 夜间 .07，可在「外观」里关掉）。没有渐变、没有毛玻璃、没有发光——海报感的重量靠纸色和留白，不靠特效。

**② 排版是印刷。**
元数据用等宽大写 + 字距：`目录 / INDEX`、`SECTIONS / 01-07`、`PROGRAMME · 30 TRACKS`、`SIDE A · 01`、`PRINTED IN THIS ROOM / 2026`。
标题下面一根 1px 墨线；栏目用直角方标 + 左标尺（`▍`）；数字用等宽体对齐。这些是印刷品的排版习惯，不是网页习惯。

**③ 强调是印章。**
唯一的高饱和色是朱砂 `--pr-red #d8341c`。它的用法像盖章而不是像高亮：面积小、位置固定、一屏只出现几次。
C1 之后红色只剩四类用途：**主操作按钮 / 正在播放条目 / 进度头 / 每页一处品牌标点**。

---

## 2. 五个原则

新的元素、新的页面、新的状态，按这五条判断，不需要再问"这样好不好看"。

**① 直角是默认，圆角是例外。**
全项目 `border-radius: 0` 出现 106 次，是默认语言。允许的例外只有两个：胶囊标签 `999px`（15 次）、圆形头像/装饰 `50%`（14 次）。
出现 `6/7/8/9/10/12/16px` 的圆角（现存 14 处）都是旧玻璃层的残留，不构成风格。

**② 线是结构，不是装饰。**
线只有三个职责：分区（1px 墨）、分表（1px hair）、分弱（1px hair-2）。一个区域只用一种线，不叠加。
不为"看起来丰富"加边框；不用 1px 实线做纯装饰框——线一旦不承担分组，就该删。

**③ 红是印章，不是高亮。**
红只给：主操作按钮、正在播放的条目、进度头、页标题的句号（每页一处品牌标点）。
**不允许**：红边框、红 hover、红图标、红圆点、红色滑块、红色焦点环、给次级按钮上红。
需要"更醒目"时，先试加粗，再试加深灰，最后才考虑红。

**④ 字重优先于颜色。**
选中/当前/强调 = `font-weight: 700` + 墨色，而不是换红/换蓝。
这条在 C1 已落地：导航选中、设置 tab 选中、循环/随机开启、开关 ON 全是墨色 + 700。

**⑤ 空与灰承担分组。**
分块靠间距（24/30/40）和留白，不靠新增底色或边框。灰阶只有五档（见 §3.1），不做第六档。

## 3. 五张规则表

### 3.1 色

| 角色 | token | 值（日间 / 夜间） | 允许用在哪 | 禁止 |
|---|---|---|---|---|
| 纸 | `--pr-paper` | `#f3f1ea` / `#171613` | 页面底、卡面 | 用在文字上 |
| 纸-2 | `--pr-paper-2` | `#ece9df` / `#211f1a` | 次级面（表头、面板） | 大面积铺满一屏 |
| 纸-3 | `--pr-paper-3` | `#e4e0d4` / `#2b2822` | 凹陷面（证照框、输入区） | 与纸-2 相邻造成脏 |
| 墨 | `--pr-ink` | `#17150f` / `#eee9dd` | 主文字、主按钮底、主分隔线 | — |
| 墨-2 | `--pr-ink-2` | `#5f5a4e` / `#b9b0a0` | **正文/说明默认色**（对比度 6.5:1+） | — |
| 墨-3 | `--pr-ink-3` | `#8b8578` / `#918878` | **仅装饰性微标**（对纸 3.0:1，禁止做正文） | 正文、状态、可读信息 |
| 朱砂 | `--pr-red` | `#d8341c` / `#e26047` | 主操作、正在播放、进度头、句号 | 其余一切 |
| 黄铜 | `--pr-brass` | `#8a6a2f` / `#c5a86c` | 「已登录」「本地目录」等**状态徽章** | 主操作 |
| 发丝 | `--pr-hair` | `rgba(ink,.24)` / `rgba(ink,.25)` | 分区细线、表格线 | 文字 |
| 发丝-2 | `--pr-hair-2` | `rgba(ink,.11)` / `rgba(ink,.12)` | 更弱的行分隔、hover 底 | 主分隔 |

裸 hex 现存约 280 处 / 70+ 个值（`press.css` 80、`shell.css` 49、`reboot.css` 47…），**这些都是历史遗留，不是新写法的示范**；新增样式一律走 token。

### 3.2 字（12 级阶梯，B1 已落地）

| 字号 | 角色 | 典型用途 |
|---|---|---|
| 48px | 场景大标题 | 舞台「LIVE TONIGHT」（衬线） |
| 33px | 页标题 | 「在线。」「收藏。」「设置。」 |
| 26px | 区块大标 | 登录面板 h3、空状态主文案 |
| 22px | 区块标题 | 详情页标题 |
| 18px | 曲名 / 大数字 | 首页曲名、统计数字 |
| 15px | 正文 | 段落、说明 |
| 13px | 行名 | 列表主字段、按钮文字 |
| 12px | 次要说明 | 副标题、hint |
| 11px | 元数据 | 时间、来源、行尾动作 |
| 10px | mono 标签 | `目录 / INDEX`、`PROGRAMME` |
| 9px | 极小 mono | 表头、角标 |
| 8.5px | 微标 | 统计下的英文注（TRACKS / MINS） |

字体三角：`--pr-disp`（Bahnschrift，仅品牌与少量大标）、`--pr-sans`（正文）、`--pr-mono`（元数据/数字）。
**禁止**：直接写字体栈（现存 10 处 `"Cascadia Mono"`、`"Microsoft YaHei UI"`、`"DengXian Light"` 直写，应改 token）；新增字号；`clamp()` 之外的自创中间值。

### 3.3 线

| 线 | 用法 | 数量 |
|---|---|---|
| 1px `--pr-ink` | **分区**：页标题下、栏目标题下、模块之间 | 27 处 |
| 1px `--pr-hair` | **分表**：表格行、卡片边 | 36 处 |
| 1px `--pr-hair-2` | **分弱**：同一列表内的行、hover 底 | 5 处 |
| 1px dashed `--pr-hair` | **空状态框**（唯一允许虚线的场景） | 6 处（其中 1 处仍是红虚线，待改） |
| inset 2px 标尺 | **选中/正在播放**：墨（选中）、红（正在播放） | 红 9、墨 2 |

规则：一段区域只用一种线；主分隔用墨，其余用发丝；线宽永远是 1px（2px 只用于 inset 标尺）。

### 3.4 圆角与间距

- 圆角：`0`（默认）/ `999px`（胶囊标签）/ `50%`（圆形）。**没有第四种。**
- 间距阶梯：`4 / 6 / 8 / 12 / 16 / 24 / 30 / 40`。页面左右边距 24–36，区块间距 24–40，行内 6–12。
- 行高：正文 1.6–1.75；标题 0.88–1.05（大字紧、小字松）。

### 3.5 材质

| 材质 | 状态 | 规则 |
|---|---|---|
| 纸纹颗粒 | 保留 | `#rs-grain`，日 .12 multiply / 夜 .07 screen，**必须可关**（外观面板） |
| 投影 | 极克制 | 只有弹层与悬浮元素有影，且必须用 `--pr-hair` 系配出来的双层影，不写死 rgba |
| 毛玻璃 | **已退役（无渲染、无 token）** | 全站 18 处 `backdrop-filter` 声明都是 `none`；14 个 `--rs-*` 变量定义已删除、52 处引用归零，`--pr-*` 是唯一视觉 owner |
| 渐变 | 仅舞台 | 舞台红幕布是唯一允许大面积渐变的地方（场景，不是 UI） |

## 4. 组件规则

**按钮只有三形态**（B2 已落地；改造前是 8 个类族、30 种计算样式签名）：

| 形态 | 长相 | 用在哪 | 类名 |
|---|---|---|---|
| 主操作 | 朱砂实心 + 纸色字 | 继续播放、扫描文件夹、登录、添加文件夹、打开目录、播放这首 | `.rs-btn.primary` |
| 次操作 | 纸底 + 1px 墨边 + 墨字 500 | 加入节目单、刷新、导入歌单、重新扫描、节目单/进入舞台、窗口「账号」 | `.rs-btn`（小号 `.rs-btn.sm`） |
| 静默 | 无框，墨-2 文字，hover 转墨 + 下划线 | 换一张、用 Cookie 登录、打开/删除/取消/关闭/重置、行内次要动作 | `.rs-btn.quiet`（可叠 `.sm`） |

另外三个**不是按钮**的原语，不要和按钮混用：分段 chip（`.rs-chip`，12px/hair 边，选中墨底纸字）、开关（`.rs-switch`，墨 knob）、整行列表项（`.rs-row` / `.pg-row`）。

**危险操作**（删除/移除/退出登录）：默认静默形态，墨-2 色，hover 才转朱砂。不开红底、不加红边。

**标签**：mono、大写、字距 `0.14–0.16em`、10px，颜色墨-2。（现存 `目录 / INDEX` 这类标签已符合，个别页 9.5px 已并入 9/10。）

**列表行**：表头 1px 墨线 → 行间 1px hair-2 → hover 底 `--pr-hair-2` → 当前行 inset 2px 墨标尺（正在播放用朱砂）。行尾动作（播放/打开/删除）默认静默，hover 显形。

**空状态**：1px dashed hair 框 + 26px 主文案 + 12px 说明 + 一个主操作按钮。不允许第三种边框语言。

**选中态**：`font-weight:700` + 墨色（必要时加 inset 2px 墨标尺）。不用红、不用底纹色块（`--pr-hair-2` 底可以）。

## 5. 允许 / 禁止清单

**允许**
1. 用现有的 12 级字号、5 档灰、3 种线、2 种圆角。
2. 在已有形态上做微调（间距、行高、字重）。
3. 需要新的视觉标识时，用**标尺 + 字重**表达，不新增颜色。

**禁止**
1. 新增第 6 档灰、新增字号、新增圆角值。
2. 给非主操作加红（边框/底/图标/文字），用红做 hover。
3. 用 `!important` 解决层叠问题（`press.css` 现有 186 个，是历史负债，不再增加）。
4. 在 `shell.css` / `online.css` 里加视觉样式——它们是被覆盖的旧层，只留结构。
5. 用 `backdrop-filter`、发光、渐变（舞台除外）。
6. 写死颜色/字体/阴影数值；`--pr-*` 里没有就先加 token，再引用。
7. 用虚线画非空状态的框；用第三种边框语言。
8. 在标题栏重复页面内已有信息（C1 前删掉的曲名是反例）。
9. 一屏出现两个同权重的主操作（同级红按钮只能有一个）。
10. 把"装饰"当"结构"：不为丰富而加线、加框、加底色。

## 6. 每页差异与收口优先级

| 页面 | 偏离程度 | 主要问题 |
|---|---|---|
| 在线 | 中 | 分段控件、登录横幅、头版卡三套语言；旧 `online.css` 玻璃层残留 |
| 收藏 | 中 | 门禁卡与列表两套语言；来源标签曾是旧玻璃色（C1 已中性化） |
| 本地 | 低 | 搜索框、分段（全部/仅无损）、排序 chips 三种控件形态 |
| 设置 | 低 | 已统一到墨色；开关形态与按钮形态仍是两族 |
| 首页 | 低 | 基本就是这套语言的样板页 |
| 舞台 | 独立 | 场景页：允许衬线大字、红幕布、投影，**不要**拿它当 UI 样板 |
| 歌词 / 迷你 | 独立 | 阅读场景，字重与对比优先，装饰最少 |

**收口顺序建议**：先 B2（按钮 8 族 → 3 形态，影响所有页），再 B7（`--rs-*` 退役、`shell.css` 只留结构），最后才是逐页细节（空状态框、红虚线、直写字体栈）。

## 7. 怎么校验（可脚本化）

1. **字号**：`node tools/font-scale.js`（默认演练）——出现阶梯外的值就报警。
2. **颜色**：`node tools/check.js` 之后可加一条 lint——`app/renderer/*.css` 里新增裸 hex 与阶梯外字号一并报出。
3. **按钮形态**：统计各按钮族的 `background`/`border` 组合，出现在 3 形态之外的组合即偏离。
4. **截图基线**：`explore/audit/_mk.sh <page> <theme> <out.png>`（1334×747、dpr1.25、隔离 profile），改前后各截一次做对比。

## 9. 单一来源判断（为什么是 `--pr-*`，不是 `--rs-*`）

**First Principle**：用户看到的每一个像素，只能由一个样式系统决定。

**Non-negotiables**：日/夜两套主题必须一份 CSS 通吃；已有的纸面视觉（纸色、方角、mono 标签、朱砂印章、hairline）不能改；`npm run verify` 必须继续绿。

**Assumptions to Drop**："两套 token 并存更灵活"、"`shell.css` 是底座不能被覆盖"、"加 `!important` 能局部了事"——这三条都是历史惯性，已经被 186 个 `!important` 证伪。

**Smallest Sufficient Path**：`--pr-*`（17 个变量、纸面语言）是唯一视觉 owner；`--rs-*` 已全部退役（14 个变量定义删除、52 处引用归零）；`shell.css` 只保留布局与结构；`reboot.css` 保留为**唯一**的覆盖层。

**Escalation Signal**：若退役 `--rs-*` 后出现"某页没有纸面替代样式"的情况，那说明该页从未被纳入纸面体系——此时应补该页的纸面样式，而不是保留玻璃分支。

**已知代价**：`--rs-*` 退役已做完（`shell.css` 941→805 行），但代价是**必须先证明规则是死的再删**：运行时创建的 DOM（如 `#rs-menu`）静态普查是 0，靠普查判死会直接删掉活样式；正确做法是触发该组件再量。
