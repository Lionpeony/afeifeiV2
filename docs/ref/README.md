## 三条约定

1. **只读**。这里不修改、不补充。发现这里是错的，改 `00`/`01`，不要改这里 —— 两份都改就会分叉。
2. **不新增**。除非 `00`/`01` 又引用了旧仓库的某个文档，否则不加新文件进来。
3. **引用写法**。在本仓库里指这些文件时写 `docs/ref/NN-xxx.md`；在 `00`/`01` 里保留原写法 `docs/NN`，读者按上表对照。
