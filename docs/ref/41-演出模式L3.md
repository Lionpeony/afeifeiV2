# 41 · 演出模式（L3）· three.js + GSAP

> 阶段 1–8 见 [32](32-React迁移-阶段1设置页.md) ~ [39](39-React迁移-阶段8登录弹窗.md)，引擎外置见 [40](40-舞台引擎外置.md)。
> 本文记录 **L3 演出模式**：它是什么、怎么实现、以及踩过的坑。

---

## 0. 三层结构（先看懂这个再改代码）

| 层 | 是什么 | 动还是静 |
|---|---|---|
| **L1** 日间界面 | 首页 / 曲库 / 收藏 / 设置 | 纸面，静止 |
| **L2** 播放页（舞台页） | 封面 + 歌词 + 控制台 | 半静止，只有封面随节拍微动 |
| **L3** 演出模式 | 独立覆盖层，熄灯后进场 | 动，three.js 场景 + GSAP 编排 |

**L3 不自动跳转**：点控制台的「进入演出」按钮，或影院模式按钮；Esc 退出。
L3 打开时 L2 整片退场（`body.theatre-on`），用户看到的是另一个空间。

## 1. 依赖

```bash
npm --prefix app install --save-dev three gsap
# three 0.187.0 / gsap 3.15.0
```

`app/renderer/lib/vendor-entry.js` 把两个库挂到全局：

```js
import * as THREE from "three";
import gsap from "gsap";
window.__three = THREE;
window.__gsap = { gsap, default: gsap };
```

`tools/build-ui.mjs` 的 ENTRIES 里注册：

```js
{ in: "renderer/lib/vendor-entry.js", file: "../lib/vendor.bundle.js" }
```

> **注意 `../` 前缀**：`outdir` 固定是 `app/renderer/features/`，要输出到 `lib/` 必须写 `../lib/`。
> 不写会静默落到 `app/renderer/features/lib/vendor.bundle.js`。

产物 **820 KB（gzip 214 KB）**，只在 L3 用到，但因为是普通 `<script>`，启动时就会加载。
如果要进一步瘦身，下一步是把 `vendor.bundle.js` 改成 L3 首次进入时的动态 `import()`。

## 3. 场景

极简，只有四个对象：

| 对象 | 说明 |
|---|---|
| `plane` | 承载封面贴图的方屏，`PlaneGeometry(1,1)`，缩放由 `fitScreen()` 算 |
| `screenEdges` | 一圈 1px 线框（`EdgesGeometry`），纸墨语言里「线是结构」 |
| `floor` | 台面横线，画在屏脚下，让屏「站」住而不是浮在虚空 |
| 相机 | 透视，**`fov` 固定 30**，只改 `aspect` |

### 三档的比例

`fitScreen()` 里：

```js
var ratio = ST.level === "cinema" ? 0.34 : ST.level === "calm" ? 0.46 : 0.62;
var side = Math.min(worldH * ratio, worldW * 0.56);
var x = ST.level === "cinema" ? -worldW * 0.29 : 0;   // 影院档退到左侧
```

## 4. 熄灯转场

`enter()` 是一条 1.36 秒的 GSAP timeline，四段：

| 时间 | 发生什么 |
|---|---|
| 0 – 420ms | `.th-veil` 遮罩从 0 升到全黑，`root` 压到 `opacity: .02` |
| 440ms | **黑场里换场**：`resize()` + `applyCover()` + `paintLyric()` |
| 560 – 1120ms | 遮罩退开、方屏从 `0.92` 推到 `1`、相机从 `z=7.4` 推到 `6.2` |
| 1360ms | `fitScreen()` 兜底，保证方屏是正方形 |

`exit()` 走同一套：遮罩升起 → 清类 → 复位。所以进出都是「灯灭→灯亮」，不是硬切。

## 5. 歌词同步

L3 不自己解析歌词，**只读 L2 的 `#lyr-stack`**：

```js
setInterval(paintLyric, 200);   // 主动轮询，不用 MutationObserver
```

`paintLyric()` 找 `.ls-row.cur` 的文本写进 `.th-lyric .now`，下一行写进 `.next`。

## 6. 踩过的坑

### 坑 1：`MutationObserver` 绑在会被重建的节点上

`#lyr-stack` 在每次切歌时被整体 `innerHTML` 重建，observer 绑的是**旧节点**，
表现为「打开后一句都刷不出来」。改成 **200ms 主动轮询**。

### 坑 2：GSAP 动画被轮询反复重启 → 文字永远透明

```js
// ❌ 每 200ms 重启一次，永远停在 opacity 0.35 的起始态
gsap.fromTo(nowEl, { opacity: 0.35, y: 6 }, { opacity: 1, y: 0, duration: 0.32 });

// ✅ 只动位移，不碰 opacity
gsap.fromTo(nowEl, { y: 7 }, { y: 0, duration: 0.3, ease: "power2.out", overwrite: "auto" });
```

**规矩**：由高频轮询驱动的入场动画，不要用 `opacity` 做起点。

### 坑 3：`camera.fov` 跟着窗口比例变 → 方屏被压成梯形

`resize()` 里如果按 `w/h` 算 `fov`，竖窗口会把方屏压成梯形。
**`fov` 固定，只改 `aspect`。**

### 坑 4：台面线写死 `y` 坐标

屏换了大小，台面线还在原地，看起来「屏浮在虚空」。
台面线必须跟随：`floor.position.set(x, -side/2 - worldH*0.045, 0)`。

### 坑 5：`prefers-reduced-motion` 把整块画布关掉

本机 Chromium 的 `prefers-reduced-motion` 是 `reduce`，原本 CSS 写了
`#theatre .th-canvas { display: none !important }`，直接黑屏。
改成 **画面保留、只是定格**（`amp = 0`，方屏不呼吸、相机不摆）。

### 坑 6：GSAP 改过 `scale` 后没有回到等比

转场里 `tl.to(plane.scale, { x: side, y: side })` 用的是转场开始时的 `side`，
而 `resize()` 中途又算过一次，两者可能不一致。
在 timeline 末尾补 `tl.add(() => fitScreen(), 1.36)`。

### 坑 7：调试脚本忘了 `enter()`

排查歌词为空时，脚本只调了 `setPage("stage")` 没调 `window.__THEATRE.enter()`，
`thNow` 恒空，误判成 bug。**L3 的所有调试都必须先 `enter()`。**

## 8. 三条配色红线（改 L3 之前先读）

1. **色相不漂移**：夜间三档都是 H≈91.8°（暖黄），日间 H≈93.6°。加新颜色先算 okLCH。
2. **红永远同一块**：夜 `#e26047` / 日 `#d8341c`，不许更亮、更大、更多处。
3. **层与层不新增颜色**：L1/L2/L3 用同一套 token。L3 的「暗」是 `color-mix(in srgb, var(--pr-paper) 46%, #000)`，
   不是新定义一个黑色。
