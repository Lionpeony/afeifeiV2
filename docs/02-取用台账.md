## 已取用

| 取了什么 | 从哪 | 为什么取 |

| `scripts/lint.mjs` 的规则 1 骨架 | 旧仓库 `tools/check-layers.mjs` | 文件遍历 + import 解析 + 层判定这套结构已经验证过；只改了 `LAYERS` 表与层名，逻辑重写反而引入新 bug |
