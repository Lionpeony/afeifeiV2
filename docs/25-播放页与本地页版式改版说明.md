# Windows 桌面版播放页与本地页大改说明

> 范围：只改 `.impeccable/mocks/decision/r4-the-line.html` 与 `l5-living-shelf.html` 两份独立原型；不改生产 UI。用户已明确：这是只用于 Windows 电脑的播放器，不需要手机端版式；本地页可以大改；拒绝普通播放器式“统计卡 + 专辑卡片墙”。

## 设计判断

旧本地页的问题不是小细节，而是整页视觉系统不统一：主体是冷纸印刷目录，右上又放一块巨大深色数字牌，中间再用透视、斜插、厚边和浮影把封套做成悬浮道具。它们像三个不同页面拼在一起，也没有让用户更快找到曲目、看清目录或开始播放。上一轮把唱片缩小、压平，尚未完成宏观重排；本次不沿用那套缩小版唱片横带。

播放页的「线即歌」机制有辨识度，因此保留机制本身，不保留目前互相争夺注意力的排版：地形尺、巨歌词、状态 micro-label 和 demo 浮层需要形成一个明确的阅读次序。

## 目标用户与平台

- 唯一目标平台：Windows 桌面常驻播放器窗口。
- 主要输入：鼠标、键盘；宽屏/中小桌面窗口。
- 本轮不做手机/触屏布局，不以手机断点验收。
- 设计目标：有产品自有辨识度、信息密度适合桌面、不是换配色的通用播放器布局。

## 共用视觉语言

- 保留冷纸、墨色、电子蓝、酸橙小型 cue、发丝线、目录编号/时间码等共同词汇。
- 主要层次通过版心比例、排字尺寸、对齐线和信息密度建立；不是给所有东西套卡片。
- 封面按曲库内容展示，不把抽象渐变封套伪装成真实唱片/书本材质；封面带是目录内容而非 3D 装饰舞台。
- 蓝色只标当前、选中、主要操作；酸橙色只做次级状态提示，不与当前歌词蓝色叠加成多重强调。
- 标题、曲目表、扫描/错误/空态使用同一套边线、字级和留白规则。

## 本地页：整页重构为桌面声音索引

### 版式
1. **固定导航书脊**保留，右侧为完整工作面。
2. **页头作为单一工具栏**：左侧为「本地」标题与一句用途说明；搜索、目录/架位/艺人切换、扫描入口在标题带下方连续排列。示例库来源只做轻量注记。
3. **馆藏计数变成索引行**：曲目/专辑/艺人数量与扫描状态采用一行排版，不做巨大数字 hero、不放深色独立统计卡。
4. **主工作区采用“目录 + 侧注”而不是“卡片墙 + 卡片墙”**：曲目目录占主宽度，右侧窄栏是文件夹、歌单、最近扫描等真实辅助信息；数据用表格线与文本层级组织。
5. **取消独立新入库唱片墙**：不在列表上方再放一排大封面。将正在播放/最近加入作为主目录前的短索引带（小封面、曲名、来源/加入时间），位置贴近列表、单行、同一基线；当前项用蓝色细定位标识。
6. **架位视图仍保留专辑封面，但作为规整平面目录**：同一尺寸、同一网格、无随机缩放、无斜插透视、无纸叠厚边、无呼吸动画；标题/艺人/曲目数贴近封面，帮助扫描和点击，而不是展示“漂浮的书”。
7. **艺人视图是排版索引**：按首字母分组、可直接过滤/播放，不再扩展成另一个容器套件。

### 状态
空库、扫描中、无结果、元数据编辑都维持当前任务位置和操作语义；明确标注演示数据，避免虚构计数被误读成真实曲库。桌面宽度变化时缩侧栏与非关键列，不跳成手机导航。

## 播放页：线即歌的节目单版心

1. 顶部一行交代曲名/艺人、来源与队列位置；删重复的状态小标签。
2. 时间地形缩成紧凑“演奏尺”：刻度、段落区间、播放头共享同一时间轴；声纹强度退到辅助层，安静/暂停态仍能辨认播放位置。
3. 歌词纵向阅读顺序固定：前句（低权重）→ 当前句（焦点）→ 译文 → 下一句（辅助）；当前词只用字重与蓝色承担状态，不加第二条荧光底装饰。
4. 右侧是真实播放序，视觉上像曲目目录，不重复封面墙；底部只保留一次全局 console。
5. 背景回归平纸，移除大面积光晕；焦点由真实歌词、地形位置和段落定位构成。
6. 播放/暂停/加载/无歌词/无封面/错误共用相同版心锚点；视图演示开关不能压住歌词或 console。

## 验收

- 只验 Windows 桌面窗口：1440×900、1280×800、1024×768；不测手机。
- 播放页看播放、暂停、无歌词、错误：能否先读到当前曲，再顺着同一播放轴找到当前词/段落/队列。
- 本地页看目录、架位、艺人、空库、无结果：3 秒内能否知道如何搜索和播放；架位是否像目录而非浮空书本；顶部摘要是否退回次要层级。
- 使用 Electron `scripts/mockup-shots.mjs` 捕获桌面状态并肉眼检查。检测告警如实记录，不用微调小字替代版式判断，也不改生产界面。
