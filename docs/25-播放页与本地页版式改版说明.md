# 播放页与本地页：吸收「少女乐队后台」语言

> 范围：只改 `.impeccable/mocks/decision/r4-the-line.html`（播放页）与 `l5-living-shelf.html`（本地音乐），不改生产 UI。
> 语言来源：`AFEIFEI+二次元少女乐队音乐播放器+·+重设计原型`。只吸收它的设计系统与物件语法，不复制它的页面结构。

## 共用的后台语言

| 层 | 取值 | 在页面里负责什么 |
|---|---|---|
| 底色 | 奶油纸白 `#FFF8F5` / 暗色 `#2A2438` | 常驻窗口的“后台灯” |
| 主交互 | 莓果粉 `#D63384` | 当前播放、主操作、进度 |
| 装饰 | 樱粉 `#FF6B9D`、薰衣草 `#7B5FC9`、薄荷 `#7EC8E3` | 胶带、路径、波形 |
| 印章 | 珊瑚 `#C62A3F` | 拨片、喜欢、强调标记 |
| 高亮 | 马克笔黄 `#FFD166` | 手写划线、长按标记 |
| 字体 | ZCOOL XiaoWei / Noto Sans SC / ZCOOL KuaiLe / Zen Maru Gothic / 等宽 | 标题 / 正文 / 旁白 / 日文 / 数字 |
| 物件 | 胶带、纸卡、便签、票根、setlist、拨片、马克笔、幕布 | 每件都承载一个状态或动作，不做纯装饰 |
| 动效 | 120 / 220 / 380 / 500ms，弹簧+柔出 | 按下、换曲、进场、幕布；三档 full/lite/off |

规则：

1. **粉色只答“正在发生”**：当前曲、当前行、播放键、进度头。
2. **胶带只出现在“被临时贴上来”的东西上**：纸卡、便签、传单、setlist。
3. **拨片是身份符号**：喜欢、当前队列位、排名都可用，但同一屏不超过三处。
4. **手写体只写旁白**，不写功能名。
5. **一屏一处斜放**（±1.5°以内），倾斜是手作感，不是动效。

## 播放页：把「演出」当成播放状态的容器

保留 r4 的“一条时间线承载进度/段落/播放头”机制，改成后台语言：

1. **幕布进场**：打开播放页时左右幕布拉开，内容 60% 处浮现；关闭时幕布合拢。
2. **舞台区**：封面像拍立得/相纸——胶带、轻微旋转、拨片编号章；暂停时停止呼吸。
3. **曲目信息**：band eyebrow → display 标题 → 日文/英文乐队行。
4. **演出时间线**：一条纸面刻度尺，段落是灰色纸条；播放头是一枚粉色票根标签；**长按 550ms 标记副歌点**，临近 8 秒浮出「要来了♡」。
5. **ED 字幕**：歌词以深色半透明字幕条出现，前一句/当前句/后一句三层；无歌词时写「纯音乐 · 这首歌没有歌词」。
6. **今晚的顺序**：右侧贴胶带的 setlist 纸卡，每 4 首分一幕（Ⅰ/Ⅱ…）；随机播放时路径线变弯；切歌时上一行被马克笔划掉。
7. **底部时间线**：整场曲目按实际时长分段的横条，点击跳曲。
8. 状态：播放/暂停/加载/无词/无封面/错误共用同一版心；错误是顶部粉色告警条，不换主题。

## 本地音乐：把曲库当成后台的排练录音架

1. **保留原型的外壳**：238px 侧栏（品牌 + 六个导航 + 日期便签 + 用户 + 主题开关），顶部搜索胶囊，底部粉色播放栏。
2. **页头**：eyebrow（LOCAL LIBRARY · 这台电脑）→ display「本地音乐」→ 一句“只读路径，不改原文件”。
3. **扫描条**：虚线圈起的路径条 + “扫描本地文件夹”按钮；扫描中变成吉他滑过 + 手写“正在数文件夹里的音轨……”。
4. **三视图**：
   - 曲目：胶带纸卡上的本地文件表（封面/标题/路径/格式与大小/时长/播放），当前曲粉色高亮；
   - 专辑：把专辑做成“贴上去的传单墙”，3 列，胶带 + 轻微旋转 + 封面 + 标题/艺人/曲目数；
   - 艺人：按首字母分组的档案行，可直接筛选播放。
5. **右侧便签栏**：三张手写便签（录音笔没电、副歌太高、散场吃关东煮）+ 上次扫描记录。
6. **状态**：扫描中、空库、无搜索结果都用带胶带的空便签，并提供“添加文件夹 / 去在线搜”的出口。
7. 演示数据、模拟状态在页脚明确标注。

## 验收

- 只验 Windows 桌面窗口：1440×900、1280×800、1024×768。
- 播放页：播放、暂停、加载、无词、无封面、错误六态；时间线点击/拖动、长按标记、键盘 Space/←→、队列切歌、划掉、随机绕路、喜欢盖章。
- 本地页：曲目/专辑/艺人、扫描、空库、无结果；搜索过滤；播放栏同步当前曲。
- 用 Electron `scripts/mockup-shots.mjs` 截图，先看再评；检测告警如实记录。

## 已落地（2026-11-16）

两份原型已按上述语言重写：

- 播放页：幕布、相纸封面 + 胶带 + 拨片编号、演出时间线、ED 字幕条、setlist 纸卡（分幕/绕路/划掉）、整场时间线、六态演示、收起/返回。
- 本地页：238px 后台侧栏、搜索胶囊、扫描条与扫描动画、胶带曲目纸卡、传单墙专辑视图、艺人索引、便签栏、粉色播放栏、空库/无结果、三视图演示。
- 桌面断点：1440 / 1280 / 1024，均无横向裁切；1024 下播放页收窄封面与队列，本地页收窄便签栏并把传单改为 3 列 4:3。
