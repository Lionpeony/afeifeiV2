## 1. 播放内核

落地：`kernel/player.ts`、`kernel/queue.ts`、`kernel/store.ts`

| 能力 | 行为 |
|---|---|
| 状态机 | `idle / loading / playing / paused / ended / error`，另有 `buffering` 表示"已开始但卡住" |
| 队列 | `items` + `cursor` + `context` + `history`，shuffle 只改播放序不改队列本体 |
| 播放模式 | 顺序 / 列表循环 / 单曲循环 / 随机（带种子，可复现） |
| 队列编辑 | 追加、删除、移动、清空、恢复 |
| 失败曲目 | 标记后可在队列面板重试；成功播放后自动移除 |
| 倍速 | 0.5–2，全局单值 |
| 音调补偿 | 原生 `preservesPitch`，默认开 |
| 静音 | 与 volume 分开存，取消静音回到原音量 |
| 睡眠定时 | 存绝对截止时刻；可选「播完当前曲再停」 |
| 失败策略 | 自动跳过 / 停下等用户；连续失败熔断（`too-many-failures`） |
| 启动恢复 | 恢复上次曲目与进度，但只 cue 不自动播 |
| 错误码 | 13 个，UI 只认码不认上游原文 |

## 11. 快捷键

### 11.1 窗内（`ui/input/keymap.ts`）

| 键 | 动作 |
|---|---|
| `Space` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `Shift+←` / `Shift+→` | 上一首 / 下一首 |

| `M` | 静音 |
| `L` | 喜欢 |

| `Ctrl+K` | 命令面板 |
| `Ctrl+F` | 聚焦搜索 |

### 11.2 全局（`domain/shortcuts/index.ts`）

## 14. 已知缺口与风险

### 14.1 明确不做

同步服务器、开放 API、播客 / 有声书（`docs/23`，2026-11-04 用户定）。

### 14.2 代码里可见的未完成项

| 项 | 证据 |
|---|---|
| 町景只搬了 konbini | `machiTuning` 恒返回 konbini；kowloon / station 未搬 |
| 町景无鼓点动效 | folia 的 htdemucs 用桩代替，涟漪/闪拍待 onset 估计补回 |
| 町景镜头不可拖 | `.st-machi` 设了 `pointer-events: none` |
| 町景首次进入慢 | 着色器编译 10–30 秒，预热模块已 vendored 未接线 |
| 引导文案未提町景 | `docs/03` 遗留项 |
| 无专辑/歌手在线页 | 三家 provider 的 `canGetAlbum` / `canGetArtist` 均为 false；专辑/歌手页只覆盖本地曲库 |
