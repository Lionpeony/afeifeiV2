### 1.4 两个真实缺陷（截图时发现）

1. **最近页丢本机记录**：历史存原始播放路径（盘符大小写/反斜杠），页面直接按 id 相等查曲库 → 整页「1 条不在曲库」。改用 `trackById` 归一化。
2. **刚点的红心在喜欢页消失**：红心域没归一化 id。修在唯一写入口 `toggleLike` / `isLiked` / `setLikes`（`domain/likes/index.ts`），补单测。

### 1.5 真实账号截图

- `scripts/lib/harness.mjs`：`launch({ profile: null })` 不加 `--user-data-dir`，走真实档案；新增 `screenshot()`（CDP `Page.captureScreenshot`）。
- `scripts/account-shots.mjs`（新）：真实登录态拍在线 / 榜单 / 歌单 / 统计；昵称截图前打码；歌单页临时收藏一张拍封面墙后立即取消。
- 产物：`docs/assets/mockups/real-online.png`、`real-charts.png`、`real-chart-detail.png`、`real-playlists.png`、`real-stats.png`。
- **这些图含个人昵称 / 头像 / 歌单，已加入 `.gitignore`，只留本机**；新机器跑脚本重新生成。
- **跑之前先退出正在运行的应用**（单实例锁会让新进程直接退出）。

### 1.6 单账号模型（用户指出的核心逻辑问题）

- 新增 `ui/active-source.ts`：全局「当前音源」单值，持久化 KV `active-source`；`ui/use-active-source.ts` 给页面共用。
- `ui/index.tsx`：原来的「按注册顺序取第一个已登录账号」改为 `resolveAccountSource`——**只认当前音源，不回退**：
  - 支持账号且已登录 → 用它
  - 支持账号但未登录 → 「登录 X 后…」
  - 不支持账号（QQ / 示例）→ 「X 没有账号数据…」
- 切源时 `beginAccount("")` 清掉上一个账号的绑定，账号页通过 `account-data.ts` 订阅当前源变化自动重拉。
- 在线 / 榜单 / 歌单的音源选择改为全局值。
- 真实验证：默认网易云 43 首红心 → 切 QQ → 0 首 + 不支持提示 → 切回 → 43 首恢复。

### 1.7 QQ 账号接口

- `main/net/qqClient.ts` 白名单与实现：`daily`（`/user/daily-songs`）、`likedSongs`（`/user/liked-songs`）、`guessYouLike`（`/user/guess-you-like`）、`songInfo`（红心前取数字 id）、`like`（POST `/user/song/like`）。
- `capability/sources/qq/index.ts`：新增 `account`，红心分页上限 2000；`listeningHistory` 如实报「不支持」（qq-music-api 3.3 没有历史路由，folia 也没有）。
- 依据：folia 的 QQ provider 用的是同一个 `qq-music-api` 包，路由一致。

### 1.8 账号区与 QQ 会话续期

- `ui/live/AccountMenu.tsx`（新）：账号面板——当前头像/昵称 + 可登录源列表（登录态、切换、退出、登录）。
- `ui/live/StationRuler.tsx`：站尺右端账号入口（头像或状态点 + 昵称）。
- `main/net/neteaseClient.ts`、`main/ipc/qq.ts`、`contracts/ports.ts`、`ui/services.ts`、`ui/bootstrap.ts`：profile 增加 `avatarUrl`。
- `main/net/qqClient.ts`：按 folia `qqSessionRefresh` 补续期——启动与每小时调 `/login/refresh`，rotated 时换新 token；退出时停定时器。**这是「退出几次后 QQ 登录态丢失」最可能的修复，但还没在真实 QQ 登录下验证。**

### 1.9 首页与示例音源

- `ui/live/LiveHome.tsx` 整体重写：首页 = 当前账号每日推荐（30 首封面墙）；不再展示本地排播。
- 删除 `ui/live/ProgramTape.tsx`。
- `bootstrap.ts` 不再注册示例音源（模块保留为单测夹具）。
- `ui/index.tsx` 新增「装配完成 Promise」：首页在首帧就挂载，账号请求等 services 就绪再发——修掉「首帧拿空列表后永不重试」。
- 冒烟同步：在线音源断言改为「有网易云/QQ、没有示例音源」。
- 真实截图：`docs/assets/mockups/real-home-daily.png`。
