## 二、LyricDoc（已落 `src/contracts/lyric.ts`）

六个关键设计决定：

1. **行号 = 数组下标**，段落用 `lineIndexes` 引用行——两层数据不重复存
2. **`words` 可空**：有逐字做卡拉OK，没有就降级整行——**渲染器必须按 `hasWordTiming` 分支**，不许假装有
3. **`quality` 三档驱动界面**：`exact` / `estimated` / `none`。C1 蓝图的「结构 · 估算」虚线态就是它
4. **`segments[].confidence < 0.6` 用虚线边界**——不确定就自己说明，不假装精确（15 §五）
5. **`offsetMs` 属于 doc**：用户调偏移是数据操作，不是 UI 状态
6. **`cursorAt(doc, ms)` 是纯函数**：任何视图都能调，结果一致——这是「唯一真相源」的技术保证

### 数据流

```
LRCLIB / 内嵌 LRC / 在线接口
        │ 解析（LRC / QRC / YRC）
        ▼
  RawLyric（原始行 + 时间戳）
        │ 段落聚类（间隔 + 文本模式，50 §6）
        ▼
  LyricDoc ──┬─▶ 六套播放样式（cursorAt 驱动）
             ├─▶ 歌词页（翻译双语）
             └─▶ 报告页（只读统计）
```

### 实施顺序（每步可验收）

| 步 | 内容 | 验收 |
|---|---|---|
| 1 | LRC 解析器（行级）+ `cursorAt` | 任意 ms 返回正确行；前后边界正确 |
| 2 | QRC/YRC 解析器（逐字）→ `words` | 逐字高亮与音频对齐 ±50ms |
| 3 | 段落聚类 v1（纯间隔法） | 6 段样本全部正确；低置信标 estimated |
| 4 | LRCLIB 抓取 + 内嵌歌词读取 | 真机可取；失败回退不阻塞 |
| 5 | 翻译接入 | 双语并排；缓存 |

## 三、SourceAdapter（多源抽象，B-03 作品层）

**设计原则：作品（Work）与来源（Offering）分离。** 一首歌一个 Work，N 个 Offering。

```ts
export type SourceId = "netease" | "qq" | "kugou" | "local" | "navidrome";

/** 作品：与平台无关的"一首歌"。 */
export interface Work {
  workId: string;            // 稳定 id（标题+艺人+时长归一化后哈希）
  title: string;
  artist: string;
  album?: string;
  durationMs: number;
}

/** 来源：某个平台上这首歌的一个可播放条目。 */
export interface Offering {
  sourceId: SourceId;
  /** 该平台内的曲目 id（拿歌词/封面用）。 */
  songId: string;
  quality: "flac" | "320k" | "128k";
  playable: boolean;         // 灰歌 = false
  durationMs: number;
  coverUrl?: string;
}

/** 每个音源实现这个接口。主进程不认识 URL 含义（50 §HttpPort 原则不变）。 */
export interface SourcePort {
  readonly id: SourceId;
  search(query: string): Promise<Work[]>;
  /** 同一 Work 在本源的所有版本（原版/现场版/重制版）。 */
  offeringsOf(work: Work): Promise<Offering[]>;
  stream(offering: Offering): Promise<{ url: string; expiresAt: number }>;
}
```

**聚合规则**（B-03 的"自动选最优"）：FLAC > 320k > 128k；`playable=true` 优先；同质量取响应快的。**选择过程必须可解释**（作品层要显示"为什么选它"）。

## 四、PluginHost（A-01，R2，先留位）

- 第一版**只做内部机制**：我们自己的功能（EQ 面板 / 桌面歌词 / 翻译）注册为内置插件
- 插件声明权限（读曲库 / 改播放 / 网络请求），**没有权限的 API 不暴露**
- 复用 `main/sandbox/`：插件跑在受控上下文，崩溃不拖垮主进程
- **不做**：签名、市场、热更新（folia 那套是整个项目最重的部分，我们没生态基础）
