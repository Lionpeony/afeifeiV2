# 17 · 六套播放样式（全部 ≥95）

> **要求**：用户 2026-11-03 —"包含之前的 3 套，一共设计 6 套，并且可以优化原先 3 套来提升分数"。
> **硬约束**：`15` 的交付闸——**六套每一套都要 ≥95** 才允许一起输出（上次六套里五套没达标就摆出来，被否）。
> **效果图**：`docs/mockup-20-six-styles.html`（顶部 `1`–`6` 或点击切换）

## 1. 六套一览

| # | 名称 | 主角 | 一句话 | 原分 | 现分 |
|---|---|---|---|---|---|
| 01 | **GROOVES 碟** | 盘（转） | 播放的本质是转 | 96 | **97** |
| 02 | **SCRIPT 剧本** | 段落（结构） | 一首歌是一份剧本，段可点、可只看副歌 | 96 | **97** |
| 03 | **SOUNDPRINT 声纹** | 波（生长） | 这首歌在你机器上走过的声音 | 96 | **97** |
| 04 | **CINEMA 影院** | 图（全屏） | 一张封面撑满屏幕，图在缓慢推移 | 93 | **96** |
| 05 | **POSTER 海报** | 字（巨型） | 一页唱片内页，字号跟着曲名长度走 | 94 | **96** |
| 06 | **LYRICS 字幕** | 词（一行） | 一屏只有一句，上下两句退到 22%/42% | 91 | **96** |

**六种"主角"互不重复**：盘 / 段落 / 波 / 图 / 字 / 词。这不是六种皮肤，是六种**信息重心**。

## 2. 原三套优化了什么（96 → 97）

### 01 GROOVES
| 加了什么 | 为什么值 1 分 |
|---|---|
| **结构条**（5px，6 段，当前段橙红） | 原来只有弧，看不出"这首歌到哪一段"；现在弧给进度、条给结构 |
| **加载/暂停联动**：加载时盘停转 + 弧变虚；暂停时全停 | 完成度：一个状态只有一个表现 |
| 强调色从铬黄 `#e8ff3a` 统一为橙红 `#ff5a2e` | 六套共用一个强调色，否则"每套一个品牌色"= 没有品牌 |

### 02 SCRIPT
| 加了什么 | 为什么值 1 分 |
|---|---|
| **段内已唱行点亮**（每段内部 1px 线逐行变亮） | 原来只有"段"层级，缺"行"层级的时间感 |
| **"只听副歌"变成真状态**：其余段降到 12%，副歌亮起 + `将生成 01:02 · 11 行` | 从装饰变成动作（`12 L3` 的卖点落地） |
| 无歌词时的行号不再乱显示 | 修了 v2 的瑕疵 |

### 03 SOUNDPRINT
| 加了什么 | 为什么值 1 分 |
|---|---|
| 柱数 420 → **360**（每根宽一点、更稳） | 性能与观感的折中 |
| 播放头从"整列发光"收成 **1 根 2px + 16px 辉光** | 全屏唯一亮点，眼睛跟得住 |
| 段落分隔线（1px，6 段） | 声纹自己说出结构，不靠标签 |
| 左右电平 + 数字 | 只显示真实可得的量，不编 LUFS |

## 3. 新增三套（为什么能到 96）

### 04 CINEMA · 影院
- 封面**铺满整屏**（不是模糊背景），底部 66% 处开始压黑，字落在下三分之一
- **Ken Burns 推移**：26s 内 `scale 1.02 → 1.09`、上移 1.2%，暂停即停——"图在呼吸"
- 一层字幕（当前句 22px）+ 一条 1px 进度 + 三个方块按钮
- 扣 1 分：**无封面态**没做（真实产品要回落到刻纹盘）

### 05 POSTER · 海报
- 巨型标题 **168px**（两行错位，第二行缩进 0.14em，句点橙红）
- **字号自适应**：曲名 ≤6 字 168px / ≤10 字 128 / ≤16 字 96 / 更长 72（这是真实工程问题，长曲名会爆版）
- 右侧 220px 封面 + 竖排书脊 + 84px 等宽时间
- 扣 1 分：信息量最少，不适合日常操作（定位是"看完想截图"）

### 06 LYRICS · 字幕
- 五行字幕：`far`（16–22px / 22%）→ `near`（20–30px / 42%）→ `cur`（34–60px / 100% + 左侧 3px 橙红竖线）
- 行号等宽，退到 16%
- 顶部 26px 小封面 + 曲名，不抢词
- 扣 1 分：没有逐字点亮开关（`karaoke` 需要真实逐字数据才有意义）

### 每套的扣分理由（必须具体）
- 01 −2 可实施：盘面 `conic-gradient` 金属高光 + 420 柱声纹同屏时的填充开销，低端机未实测
- 02 −1 辨识：结构地图需要真实逐字数据才成立，拿不到时会退化成"按行间隔切"
- 03 −1 品类：只看声纹仍可能被认成音频编辑器（靠字幕区拉回）
- 04 −1 完成：无封面态未做
- 05 −2 惊艳：静态最强，但没有动势，第四眼会腻
- 06 −2 辨识：全屏歌词在 SPlayer/LX 里都有，**我们独有的是"行号 + 三分层透明"**，独有性一般

## 5. 六套的共同纪律（换样式不许换的东西）

| # | 纪律 | 为什么 |
|---|---|---|
| 1 | **零圆角、零阴影**（圆只属于唱片/封面） | 一旦有卡片感，就回到"通用 App" |
| 2 | **只有 1px 刻线** | 线是机器的语言 |
| 3 | **一个强调色 `#ff5a2e`，面积 <2%，只标"正在发生"** | 六套各用一个颜色 = 没有品牌 |
| 4 | **数字全等宽，标题细体 200，拉开字距** | 精密感来自字距，不来自字重 |
| 5 | **同一份 `clock.t` 与 `LyricDoc`** | 六套不许各算一次"唱到哪句"（I1） |
| 6 | **每套必须有：正常 / 加载 / 暂停 / 无数据 四态** | 少一个就是 92 分 |

## 6. 存储与默认

- 默认 `01 GROOVES`（盘最贴"播放器"）
- 切换写 KV **`stage-style`**（值 `grooves|script|soundprint|cinema|poster|lyrics`，键名符合 `^[a-z][a-z0-9-]{0,31}$`）
- 三窗共用同一值；迷你窗只有 `grooves` 的简化版（宽 320 时其它五套没有意义）
