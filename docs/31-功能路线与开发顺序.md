> 2026-11-20。定位讨论后的落地清单，按 v1.1 → v1.5 顺序施工。
> 前提判断见本文第 0 节：版权和生态差距是结构性的，不做替代品，只做「用户自持凭据、本地优先、双源可插拔的桌面播放器」。
> 每条都写清现状与验收；「已有」的部分不重复造。
>
> **2026-11-20 决策更新**（开源定位复核）：MV 播放不做；平台电台改为「用户订阅开放 RSS」；评论只读、网易云云盘不做；i18n 缓做。

## 0. 先分清三类缺点

| 类别 | 例子 | 结论 |
|---|---|---|
| 工程可解决 / 大幅缓解 | 启动慢、音质链路、下载收尾、响度均衡、更新与崩溃诊断、元数据补齐、本机推荐重排 | 排进 P0–P4 |
| 只能降低概率，不能根除 | 接口失效、`-460` 风控、接口变更、封号 | 做 adapter 探测、退避、降级链、用户自带凭据；不做对抗 |
| 不建议做 | 自有账号/会员/支付、直播、K歌、一起听、歌单协作、商店上架、听歌识曲、为省内存重写技术栈 | 明确不做，见第 6 节 |

一句话：把「寄生」做成「可插拔、可降级、用户自持凭据」，韧性会好很多；但版权与生态差距本身补不上。

## 1. 排序原则

1. **先修地基**：启动、接口韧性、降级、诊断、更新——这些会反复咬人，越晚做成本越高。
2. **再补体验**：播放与下载从「够用」到「好用」，这是本产品真正的差异面。
3. **再扩内容**：MV、电台、元数据补齐，先把候选池做大。
4. **再做智能化**：没有候选池，推荐引擎只能空转，所以推荐重排必须排在元数据之后。
5. **最后做分发**：安装包、签名、CI、i18n 只有在真要分发时才值得。

工作量口径（单人）：S ≈ 1–2 天，M ≈ 3–5 天，L ≈ 1–2 周，XL ≈ 2–4 周。

## 3. 功能清单

### P0 · 稳定性与启动（先做，收益最高）

| # | 功能 | 缺口 / 落地位置 | 工作量 | 验收 |
|---|---|---|---|---|
| 1 | 启动瘦身 | 本地 QQ API 服务现在开机就起（起不来还打 warn）；快捷键、更新检查、媒体会话注册都挤在启动路径。改为首次使用再起、非关键注册延后到窗口可见后 | S–M | 冷启动到可交互 ≤ 2s；未用 QQ 时不启动本地服务；启动日志无 QQ 服务失败噪音 |
| 2 | 在线链路韧性 | 在 `capability/sources/*` 与 `main/net/qqClient.ts` 加强：字段探测（读不到主字段时试别名）、请求节流/退避、错误分类统一（风控 / 未登录 / 无版权 / 网络） | M | 上游字段改名时降级而不是整块空白；连续失败进入退避，不连环重试；每类错误有稳定的人话文案 |
| 3 | 降级播放链 | 在线取流失败 → 明确提示可切源 → 已下载同曲 → 本地同曲（需要标题/歌手/时长模糊匹配）。接在现有 `handleFailure` 决策上 | M | 断网或风控时仍能播本地与已下载曲目，不出现「点了没反应」 |
| 4 | 诊断包导出 | 崩溃文件已有，补「一键导出诊断包」：版本、平台、最近日志（脱敏）、崩溃栈、设置快照 | S | 用户能导出一个可直接发送的 zip；密码/token/手机号脱敏 |
| 5 | 自动更新 | 主进程补版本检查 + `electron-updater` + GitHub Releases；发布物附校验和 | S–M | 新版本可提示、下载、安装；包体可校验；失败不打断播放 |

**进度**：#1 已完成（2026-11-20）。网易云改为「按路由 require」、QQ 本地服务改为 `ensureQqBackend()` 按需启动、托盘延后一拍、渲染层 `app.js` 压缩。同机实测（3 次中位数）：进程 → 主窗口就绪 **5.2s → 1.3s**；进程 → 启动层退场（可交互）**5.5s → 2.3s**；第一次 QQ 调用（懒启动整条链路）**0.5–0.7s**。启动日志在网易云音源下不再出现 QQ 服务噪音。残留：网易云首次网络请求仍会在主进程付一次 request 链载入（约 1.7s），属于 #2 的 worker 化范围。

## 5. 硬依赖

- #7 音质联动要排在 #6 下载收尾之后：大文件才需要续传与音质一起考虑。
- #16 推荐重排要排在 #13 元数据补齐之后：候选池信息不完整时，打分没有意义。
- #5 自动更新要排在 #22 安装包之后：没有安装包就没有更新载体（开发期可先用手动包验证）。
- #11 / #12 都必须先做接口探测（复用 #2 的探测与错误分类），再写 UI；#11 已取消，该条只约束 #12 的 RSS 抓取错误分类。

## 7. 度量

| 指标 | 目标 | 测试方式 | 现状（2026-11-20） |
