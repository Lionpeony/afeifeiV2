# 29 · 首页视觉体系 v1：今日发行（Today's Release）

> **地位**：首页（LiveHome）+ 全局交互组件（按钮 / 操作栏 / 浮层）的整套重设计规格。2026-11-10 定稿，未实施。
> **结论先行**：现版首页的问题不是配色（青瓷已换装），是**组件语言无身份**。本体系把首页定义成「厂牌今日发行的发行页」，所有交互组件从印刷物语法里长出来——目录号、侧标、引导点、唱针灯、发丝线。概念稿：`design-demos/home-v2/index.html`（真机截图 `docs/assets/mockups/home-v2-release.png`，自评 95）。
> **硬约束**：不碰播放页场景层（A-10）；青瓷 token（29 §3）是唯一颜色来源；reduce 全降级；数据全部来自真实接口，不编造。

---

## 0 · 诊断：现版首页为什么必须从零

按 26/51 的评价维度逐条过，六条根因：

| # | 问题 | 证据（2026-11-10 实机） | 本体系对策 |
|---|---|---|---|
| 1 | **组件语言无身份**：胶囊岛导航是借来的 folia 语汇，白卡片网格是通用播放器脸 | 换了青瓷配色后"还是通用播放器" | §2 印刷物语法：组件全部长在发丝线上 |
| 2 | **卡片网格是占位式布局**：封面圆角卡 × N，无排版层级，封面好坏决定页面好坏 | 真封面花/乱/风格不一时整页碎 | 曲目表用文字排版承载（封面只在 hero 出现一次） |
| 3 | **长标题无排版策略**：《Chaikovsky（战个痛快）》级标题在 hero 折三行，字号被内容绑架 | 用户实机截图 2026-11-10 | §6.2 字号降档规则（>14 字符 58→44px，>24 字符截断 + title 全文） |
| 4 | **底部操作台 11 个控件挤一行**：音效/定时/队列/歌词/迷你与走带混排，无分组语义 | 实机截图 | §6.5 双层操作台 + 模式文字钮分组 |
| 5 | **在播与推荐的关系用户不可控**：hero 跟随播放状态自动投影，用户不知道"它为什么变成这样" | onAirProgram 投影逻辑 | §7 三态投影 + 钢印文字明示（今日发行/客座发行/待机） |
| 6 | **纯装饰件**：STEREO L/R 虚线没有任何信息 | 实机截图 | 删除；该位置给真的（曲目表页脚统计） |

**保留项（现版做对的，本体系继承）**：真实封面在 hero 的大图呈现；每日推荐 06:00 换新语义；尾曲环回循环；刷新/完整列表入口；账号弹层（已按双栏实装，不动）。

## 1 · 体系概念

**首页 = 厂牌「AFEIFEI RECORDS」今天的发行页。**

每天 06:00 换新的推荐就是今天的发行。页面的一切是这张"唱片"的随附印刷品：封套（左）、曲目单（右）、唱机操作台（底）。播放状态是一盏挂在封套上的唱针灯；换曲是"发行页翻到下一首"；从榜单/歌单点进来的歌是"客座发行"（钢印换字）。

**一句话检验**：任何新组件先问"它在这张发行页上对应什么印刷物部件"，答不上来就不许进首页。

---

## 2 · 设计铁律（六条）

1. **一条发丝线原则**：组件之间不用盒子分隔，用 1px 发丝线（--line / --line-soft）+ 留白。全页填充底色的元素**每屏最多一个**（立即播放钮）。
2. **文字即界面**：列表、状态、来源都用文字排版承载；封面只在 hero 出现一次。
3. **mono 是仪器，sans 是正文**：目录号/时间/状态/来源标签用 mono + 宽字距；曲名/正文用 sans。不得混用。
4. **一个光源方向**：高光永远来自上方（-1px 白缘），投影永远向下。已有规范（§质感升级）延续。
5. **object 而非 label**：状态（播放中/暂停/待机）做成挂在实体物上的灯牌，不做裸文本。
6. **reduce 全降级**：每条动效必须在 `prefers-reduced-motion` 下有静态终态。

## 3 · 配色与语义（token 基座，青瓷已实装）

只扩两条语义，不新增色相：

| token | 值（浅/深） | 语义 |
|---|---|---|
| `--accent` | #0e8f82 / #2ec9a7 | 青瓷印：主操作、在播、选中、品牌句号 |
| `--live-onair` | #c2620f / #e0703a | 警示橙棕：错误、退出中、暂停灯（红色已退场） |
| `--live-signal` | #3f7a96 / #7fc9d8 | 频谱/波形 |
| 新增 `--ink-faint` | rgba(23,48,44,.45) / rgba(220,235,230,.45) | 引导点、目录号、序号灰（比 --fg-dim 再弱一档，仅印刷装饰件） |

纪律：**每屏 accent 出现次数 ≤ 6**（品牌句号、导航下划线、唱针灯、在播行、立即播放钮、进度唱针）。

## 4 · 栅格与字号阶

- 设计宽 1120（1024–1440 自适应）；左右边距 56px；三列 330 / gap 52 / 1fr。
- 垂直：顶栏 64（含发丝线）/ 主区 / 操作台 88（含发丝线）。内容区最小高 440。
- 间距系统：8 的倍数；组件内 12/16，组件间 24/32，区块间 48。
- 字号阶（五档，不得越阶）：**58 / 24 / 14.5 / 12 / 10.5**；行高 1.08（大字）–1.7（正文）。
- 直角为默认；圆角只给"实体物"（封面 12px、按钮胶囊 999）。

## 5 · 组件规格

### 6.1 顶栏 `home-top`（重定义）
- 结构：一根 64px 发丝线行。左：**字标组**（青瓷句号 7px + `AFEIFEI` disp 14px/0.24em + `RECORDS` mono 8.5px/0.3em）；中：导航项；右：搜索 + 账号。
- 导航项：纯文字 12.5px，on 态 = ink 加粗 + 底部 2px accent 线；**点击区为整行高（44px）**；无胶囊、无底色。
- 搜索：`⌕ 搜索音乐` 线框（下边框 1px），聚焦展开 180→260px（180ms ease-out）。
- 账号：头像 30px 圆（ring 1px hair）；**不显示文字**，状态由账号弹层承载。
- 断点 <1180：溢出项收 `⋯` 菜单（含全部隐藏项）。

### 6.2 发行区 `release-hero`（重定义，替换现 hero）
- 左 330px：**封套**（封面图 or 生成封套），`rotate(-1.6deg)`，书脊 7px 高光条，四层影；叠**目录号**（mono：`CAT.{源}-{YYYYMMDD}-{序号}`）、**钢印**（54px 圆，2px accent 描边，文字随投影态：今日发行/客座发行/待机）、**唱针灯牌**（深底 chip 贴右上角，内容 `PLAYING · {侧标}` / `PAUSED` / `STANDBY`，灯 2.2s 呼吸）。
- 封面缺失时：生成封套 = 深青底 + 曲名竖排 + 青瓷线框（复用现有 NightCoverArt 语言，去电台词）。
- 右 1fr：
  - kick 行：mono `TODAY'S RELEASE · 每日 06:00 换新 · 共 N 首 · 循环`（accent，来源名嵌 `· 来自 {origin}`）
  - **标题**：58px/1.08/700；>14 字符降 44px；>24 字符单行截断 + title 全文
  - 元数据行：`{艺术家} · {专辑} · {时长}`，5px 青点分隔
  - 操作组：**立即播放**（P0 填充胶囊，全页唯一）+ 加入队列（S ghost）+ ♡（I icon）
- 断点：<1180 封套 260px；<1024 hero 全宽、封面 220px 居左。

### 6.3 曲目表 `release-tracklist`（重定义，替换卡片网格）
- 表头：`接下来播放`（13.5px/0.1em，加粗）+ 右侧 mono `SIDE A · N TRACKS`；表头底线 2px ink。
- 行：`{侧标} {曲名} ······ {时长}`——侧标号 mono 10px（按播位映射 A2/A3…B1），曲名 14.5px，**引导点** flex 撑满（1.5px dotted，--ink-faint），时长 mono 11px 右对齐。
- 在播行：侧标与曲名 accent 加粗 + 3 根律动条（12px，1s 错相）；hover 行底 tint .045。
- **hover 浮现播放钮**：26px 圆 accent 填充，`opacity 0→1 + scale .8→1`（120ms）；在播行常驻为灰描边暂停符。
- 点击行为：点行 = 从该首起播（队列=整份推荐），与现版一致。
- 完整列表：无分页——行数多时表内滚动（max-height + 渐隐遮罩），替代现版"展开/收起"。

### 6.4 按钮体系（全局语义，覆盖首页与全部交互组件）
| 级 | 名 | 形 | 用在哪 |
|---|---|---|---|
| P0 | primary | accent 填充胶囊，全屏唯一 | 立即播放、登录（账号弹层）、发送验证码 |
| P1 | switch | accent 12% tint 胶囊 | 切换到此账号、换一张（进行中动作） |
| S | ghost | 1px --line-strong 胶囊，hover 变 tint | 加入队列、退出登录、取消 |
| I | icon | 32px 圆 hairline ghost，glyph 居中 | ♡、迷你窗、全屏 |
| T | text | 文字 + on 态 2px accent 下划线 | 循环/音效/队列/歌词/迷你、导航 |

状态规范：hover = tint +8%（140ms）；active = scale(0.97)；disabled = opacity .45 + cursor default；loading = glyph 换 12px 旋转圈。**禁止**：渐变按钮、阴影按钮（按钮不用投影，浮层才用）。

### 6.5 操作台 `transport-deck`（重定义，替换现控制台在首页的呈现）
- 双层 88px，顶一根发丝线，底色 = 面板 60% 透明（内容透出，不压场景）。
- 上层：`{当前} mono / {总} mono` + **唱针线**（2px 底轨 16% ink、已播 accent、唱针 10px 圆 + 3px accent 光环）+ 总时长。
- 下层三分区：`{曲名 + mono 来源行}` | 走带键（⏮ ⏯ ⏭；⏯ 46px **2px ink 描边圆**，hover 反转填充——全页唯一的"反白"件） | 模式文字钮（循环/音效/队列/歌词/迷你，T 级）。
- 音量：并入 T 级「音量」hover 弹出小滑杆（复用 vol-pop，改 T 级触发）。
- 断点 <1180：模式钮 >3 个收 `⋯`。
- **控制台只在首页消失**：其余页面维持现版控制台（操作台是首页专属件；切到别的页，底部回到现版控制台——本体系只覆盖首页与其组件语言，组件规范（§6.4）全局通用）。

### 6.6 浮层语言（对齐已实装账号弹层）
- 结构：发丝线框 + 双层影（`0 36px 90px -26px` 环境影 + `0 2px 10px -2px` 接触影 + `inset 0 1px 0` 亮缘）+ accent 单强调。
- 位置：居中 700×420 起（账号 700×420 / 后续弹层按内容缩放）；遮罩 rgba(12,21,20,.38)。
- 已实装对齐：账号双栏弹层 ✓。待对齐：队列（qp）、音效/睡眠/倍速（vol-pop 族）——按 §6.4 按钮级与 6px 凹槽轨规范收编，不改结构。

### 6.7 状态三件套
- **加载**：封套 = 骨架（斜置矩形 + 同角度 shimmer）；曲目行 = 虚线引导点骨架（同语法，虚线变成点阵）。
- **空态**：曲库空 → 发行页「未登记」：封套虚线框 + 钢印「未登记」+ 登录入口（P0）。
- **错误**：曲名行原位替换为错误文案（onair 橙）+ T 级「重试」；不弹窗。

## 7 · 动效规范（全 CSS，reduce 全降级）

| 场景 | 效果 | 时长 |
|---|---|---|
| 首次进入 | 封套 rotate 落位 + 行错落浮入（40ms 节拍） | 520/220ms |
| 换曲 | 曲目表 on 标记迁移 + hero 文字 pane-swap（200ms）+ 封面 crossfade | 200/260ms |
| 点行播放 | 行 hover 钮按压 scale .97 → 全页换台闪变（已有 460ms） | 已有 |
| 换一张/刷新 | 封面 crossfade | 260ms |
| hover | 行 tint、钮 tint（140ms） | 140ms |
| 灯 | 唱针灯 2.2s 呼吸、律动条 1s 错相 | 常驻 |
