## 1. 共享骨架 vs 三包覆盖（结构不变原则）

四个主题包**共用同一套结构骨架**（顶栏 / 侧栏 / 三栏播放页 / 底栏），三包只覆盖**视觉层 token**：颜色、材质、字体角色、形状语言、动效节奏、播放页栅格（`--np-*`）。**组件结构实例不变**，只换栅格与摆放——这是「听歌 = 一场有节目单的演出」在不同世界观下的换装，而不是三套独立界面。

## 2. 逐包设计

### 2.1 无滤镜·冷灰（GBC）

- **身份**：导播监视器 / 印刷杂志。冷灰纸 × 荧光洋红 × 冷青，硬派、粗糙、反叛。
- **色彩（亮）**：纸底 `#EDEFF1`、次层 `#E0E3E7`、卡片 `#FFFFFF`；正文 `#16181D`、次 `#4A5260`、弱 `#5A6270`。
  - 装饰 `--pink-400 #FF2D9B`（荧光洋红，**只做装饰**，白字仅 3.4:1 不达 AA）；交互 `--pink-600 #C2187A`（白字 5.67:1）；按下 `#8E1058`。冷青 `--lav #0E7C92`、`--mint #3FA7BC` 做次级点缀。
- **材质**：半调网点（`radial-gradient` 6px）、`grain .5`。
- **字体**：display `Impact / Arial Narrow / 雅黑`；`title-transform: uppercase`；无手写体（`--font-hand = body`）。
- **形状**：印刷方角——card 10 / sheet 14 / btn 10；**硬偏移阴影** `4px 4px 0 #16181D`（无模糊）。
- **动效**：短促硬切，`--dur-fast 140ms / base 250ms`，`ease-curtain`。
- **版式（`--np-areas`）**：`"lyric queue" "poster queue"` —— 字幕条压上沿、主监视器在下、时序表守右。
- **暗版**：底 `#0E1116`、`pink-600 #FF4FA8`、`grain .65 overlay`（图1 即暗版）。
- **播放页三区落点**：海报带 `ON AIR` 角标与荧光描边；时序表是「今晚的时序表」分幕列表；歌词区大字号反白。

### 2.2 墙角·暖米（BTR）

- **身份**：手作 zine / 墙角练琴。牛皮纸 × 橘棕 × 暖墨，旧、暖、有人味。
- **色彩（亮）**：纸底 `#F1EEEA`、次层 `#E6E0D7`、卡片 `#FBF9F6`；正文 `#3A2E26`、次 `#6B5A4C`、弱 `#6F5F52`（已压 ≥4.5）。
  - 装饰 `--pink-400 #E8A87C`（浅橘棕，禁交互/正文）；交互 `--pink-600 #A0522D`（深棕，白字 5.62:1），按下 `#743A1E`。小面积识别色：波奇粉 `#E75C8D`（红心）、舞台黄 `#FFC53D`（进度/灯）、冷蓝 `#4EA8C9`。
- **材质**：点阵纸（`radial-gradient` 20px）、`grain .35 multiply`。
- **字体**：display `Instrument Serif / Noto Serif SC`；body `Noto Serif SC`（衬线正文）；hand `ZCOOL KuaiLe`（批注/贴纸）。
- **形状**：软圆——card 14 / sheet 18 / btn 胶囊；**暖色阴影** `0 6px 18px rgba(120,80,40,.15)`。
- **动效**：`ease-spring` 回弹（保留手作弹性）。
- **版式（`--np-areas`）**：`"lyric poster queue"` —— 提词左窄、海报中、节目单右。
- **播放页三区落点**：海报贴胶带、下载区涂鸦（吉他/拨片）；节目单是「今晚的演出单」带点阵分隔；歌词卡衬线、暖色进度线（图2）。

### 2.3 迷子·雨夜（MyGO）

- **身份**：和纸手账 / 隔窗旁观。雨夜紫降暖、往蓝灰推；疏离、克制、迷茫。
- **色彩（亮）**：纸底 `#E9EFF8`、次层 `#DDE6F3`、卡片 `#FBFCFE`；正文 `#252B3A`、次 `#4F5A6E`、弱 `#586377`（已压深：`bg-sub` 上 4.81:1）。
  - 装饰 `--pink-400 #C2CBDE`（雨雾蓝灰，**禁交互**）；交互 `--pink-600 #4A5673`（深蓝紫，白字 7.4:1），按下 `#354056`。`--lav #6F8FB5`、`--mint #7FAFC9` 雨雾点缀。
- **材质**：横格稿纸（`repeating-linear-gradient` 24px）、卡片**虚线边框** `--card-border-style: dashed`。
- **字体**：body `Noto Serif SC`（衬线，手账纸感）；hand `ZCOOL KuaiLe`。
- **形状**：手绘圆角——card 12 / sheet 16 / btn 胶囊；柔阴影 `0 10px 28px rgba(37,43,58,.20)`。
- **版式（`--np-areas`）**：`"queue poster lyric"` —— 排练计划表守左、窗内舞台居中、提词纸贴右。
- **播放页三区落点**：海报像叠在窗上；「今晚的排练单」在右；**虚线歌词卡**居中、衬线斜体、大量留白（图3）。这也呼应产品名「迷子（迷途之子）」的疏离感。

## 3. 风格基准对照（ui-ux-pro-max）

| 包 | 匹配的风格类别 | 取用了什么 | 无障碍要求 |
|---|---|---|---|
| GBC | `editorial-grid-magazine`（非对称杂志网格·高对比·印刷感） | 非对称栅格、全大写、硬偏移、编号时序表 | contrast-text-4.5、visible-focus、reduced-motion |
| BTR | `anti-polish-raw-aesthetic`（纸张白 / 铅笔灰 / 牛皮 `#C4A77D` / 手绘 / 胶带贴纸） | 牛皮纸、点阵、涂鸦、贴纸、纹理 | 同上 |
| MyGO | `minimalism-and-swiss-style`（留白·高对比·网格） | 克制网格 + 衬线斜体做雨夜情绪 | 同上 |

**字体基准**：三者都属「type-as-hero」路线（display + body + mono 三层各司其职）。我们对应为：display（Impact / Instrument Serif / ZCOOL XiaoWei）+ body + `JetBrains Mono` 数字——与 skill 推荐的 sans/serif/mono tri-stack 同构。

## 4. 无障碍与对比度

- **GBC**：荧光 `#FF2D9B` 只做装饰（3.4:1 不达 AA）；交互 `#C2187A` 5.67:1 ✓。
- **BTR**：交互 `#A0522D` 5.62:1 ✓；弱字 `#6F5F52` 已压 ≥4.5。
- **MyGO**：交互 `#4A5673` 7.4:1 ✓（主播放键已改实心 + 白三角，白字 7.32:1）；装饰 `#C2CBDE` 禁文字。
- **通用**：统一 `--focus-ring` 焦点环、`prefers-reduced-motion` 全 15 个 `af/*.css` 覆盖、时长/计数 `tabular-nums`。
- **实测（2026-11-26）**：`text-3` 在 `bg-sub #DDE6F3` 上原为 4.33:1（不达标），压深到 `#586377` 后 4.81:1；右上窗控 `.np__winops`（`--text` × .72 叠底）实测 5.29:1 ✓，无需改动。

## 5. 是否符合「二次元少女乐队」——评估

**结论：概念上 100% 贴合，气质上 GBC / BTR 很准，MyGO 差一口气。**

三包分别对应三部真实的少女乐队番——本就不是泛泛的「二次元配色」，而是有 IP 锚点的世界观：

- **GBC · 无滤镜（少女乐队的呐喊）**：荧光洋红 + 冷青 + 硬边 + `REC / LIVE / ON AIR` 录影字样 = 粗糙、愤怒、川崎冷灰的舞台录影。**乐队感 > 少女感，最「酷」**，最不像通用播放器。
- **BTR · 墙角（孤独摇滚 / 结束乐队）**：牛皮纸 + 衬线 + 点阵 + 吉他涂鸦 + 胶带贴纸 = 手作废柴、墙角练琴、下北泽 Livehouse。**少女感 / 社恐感最准**。
- **MyGO · 迷子（迷途之子）**：雨雾蓝 + 虚线 + 衬线斜体 + 疏离留白 = 迷茫、雨天、解散阴影。**情绪对**；原先主播放键是浅蓝半透明玻璃、没吃深蓝紫交互色，主次偏弱、容易掉进「浅蓝通用播放器」——**已修正**（见下）。

**共同的加分项（最贴题的地方）**：三包都通过「今晚的演出单 / 时序表 / 分幕 / SETLIST / 演出时间线」把「听歌 = 一场有节目单的演出」这条产品隐喻落地——这正是「少女乐队」最该抓住的**舞台仪式感**，比单纯换配色高级得多。

### 改进落地（2026-11-26）
1. ✅ **MyGO 主播放键**：改为交互色 `#4A5673` 实心 + `--on-accent` 白三角，让唯一主操作「盖章」（呼应 DESIGN.md 的 One Mark Rule）；暗场同样实心（`--pink-600` 暗档 + 深色前景），并显式重设以赢过基座暗色规则。`player.css` `.np--mygo .np__ctrl--main`。
2. ✅ **MyGO 浅色对比**：`--text-3 #5F6A7E → #586377`，`bg-sub` 上由 4.33:1 提到 4.81:1；窗控实测 5.29:1 无需改动。`tokens.css`。
3. ✅ **BTR 主次**：海报上限 `--np-art-max` 42vh → 46vh，中栏（海报）在尺寸上先立起来。`tokens.css`。
4. ✅ **`--np-areas` 已确认接入**：`player.css:53` `grid-template-areas:var(--np-areas)` 真生效，三包栅格确实换位；截图中 MyGO 队列看似顶栏，是宽屏下 `queue|poster|lyric` 三列排列所致，非未落地。不改结构。

## 6. 风险与遗留
- GBC 的 `Impact` 是 Windows 自带字体，换机缺字会回退雅黑、掉气质——`fonts` 兜底需确认。
- 网点 / 纸纹 / 横格均为 CSS/SVG 生成，性能已过 budget；叠 `grain` 时低端机/移动端留意。
- 三包交互色与装饰色分离是硬规则：**装饰色永不做文字/按钮底**（The 400 Never Speaks Rule）。
