# 26 · 全站设计系统——冷纸 / 线即歌

> **地位**：UI 排版、质感、动效的唯一视觉权威；功能边界仍以 docs/24 为准。
> **来源**：`.impeccable/mocks/final/r4-the-line.html`（播放页）与 `l5-living-shelf.html`（本地页），2026-11-05 用户选定该方向。
> **方向决定记录**：曾以「声纹剧场升级版（浅色工作台 + 深色聆听舞台 + 唱片纹路/环形进度）」为推荐，用户要求对比昨天两份 mock 后，确认冷纸/线即歌更优——机制型惊艳（进度写进歌词字重与演奏尺）优于气氛型惊艳（深色舞台），且一套 token 贯穿 13 页、与现有登记簿血缘一致。用户原话选择：「冷纸/线即歌（推荐）」。
> **二次升级（同日）**：用户提出「打破常规播放器的固有排版，打开一眼就不一样，张扬、创新」。经三方向对比（巨字剧场 / 声浪图纸 / 演出海报），选定**巨字剧场**；结构破格程度选定**激进**——去掉左侧导航栏与底部播放条。用户原话选择：「巨字剧场（推荐）」「激进破格（推荐）」。张扬由**排印规模与结构破格**达成，不引入装饰。
> **平台**：仅 Windows 桌面窗口（1440×900 / 1280×800 / 1024×768 验收），不做手机断点。

---

## 1. 设计哲学

**整页只有一种东西——冷纸上的声音索引。** 播放器是一台「声音登记机器」：曲库是目录，播放是演奏，进度是纸面上移动的一条线。

- 记忆点是**机制**而非装饰：①「线即歌」——演奏尺上刻度/声纹/段落/播放头同轴，歌词字重随播放连续变重；②「印刷编目」——编号、时间码、字母尺、馆藏计数索引行。
- **巨字即界面**：当前句排印是页面主角（`clamp(64px,9vw,160px)`），歌词不是面板里的滚动列表，而是页面构图本身——打开播放页 = 一张正在演奏的活海报。工作页同样用巨型页名（44–64px）做每页排印记忆点。
- **激进破格**：取消左侧 76px 导航栏与底部 108px 播放条——常规播放器骨架不再存在。导航 = 页顶 44px mono 索引带 + `Ctrl+K` 命令面板；播放控制 = 索引带右端「当前曲位」+ 演奏尺 + 快捷键。
- 蓝色 `#233ff2` 只标**当前、选中、主操作**；酸橙 `#d9ef42` 只做**次级状态提示**（扫描进度、视图标记），两者不叠加强调。
- 唱片意象降格为小签名：索引带当前曲位旁一枚 24px 黑胶 mini（可旋转），不再做大幅环形或纹路主视觉。
- 层次靠版心比例、排字尺寸、对齐线、信息密度建立；**不给所有东西套卡片**，无光晕、无渐变背景、无粒子。

## 2. Token 系统（与现有 tokens.css 对接）

### 2.1 色彩（冷纸 = 日间配色）

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#f3f2ed` | 全局底色（唯一大面积底） |
| `--paper-hi` | `#faf9f5` | 输入框、侧注栏、console 等浅一层 |
| `--paper-lo` | `#e9e7df` | 代码内联、进度条槽等深一层 |
| `--paper-cold` | `#e8ebf1` | 冷调留白（可选，统计/图表区） |
| `--ink` | `#11131b` | 主文字、粗分隔线（1.5px） |
| `--ink-soft` | `#4a4f5a` | 次级文字 |
| `--ink-dim` | `#8b8f98` | 辅助文字、mono 标签 |
| `--ink-faint` | `#b9bcc3` | 最弱文字、虚线边 |
| `--accent` | `#233ff2` | 当前/选中/主操作 |
| `--accent-wash` | `rgba(35,63,242,.07)` | 播放中行、扫描条底 |
| `--signal` | `#d9ef42` | 次级状态提示（酸橙） |
| `--danger` | `#d23b2e` | 错误 |
| `--line` | `rgba(17,19,27,.18)` | 常规发丝线 |
| `--line-soft` | `rgba(17,19,27,.09)` | 行间细线 |

### 2.2 四套全局配色的映射

现有日间/夜间/棕褐/森林四套只需换纸与墨，词汇不变：

| 配色 | paper | ink | accent |
|---|---|---|---|
| 日间（冷纸） | `#f3f2ed` | `#11131b` | `#233ff2` |
| 夜间（暗房） | `#15161c` | `#e9e7df` | `#6a86ff`（同族降饱和蓝，保证 4.5:1） |
| 棕褐（牛皮纸） | `#ece4d4` | `#26221a` | `#8a4a1f` |
| 森林（绿罩） | `#e9ede6` | `#1a211b` | `#2e6b4f` |

规则：换配色只换 token 值，版式、边线粗细、组件结构一律不动；夜间下 `--signal` 提亮为 `#e4f56a`。

### 2.3 字体

| Token | 栈 | 用途 |
|---|---|---|
| `--mono` | `"Cascadia Mono","Segoe UI Mono",Consolas,monospace` | 编号、计数、时间码、字母尺、状态标签（8–12px + letter-spacing .08–.14em） |
| `--sans` | `"Segoe UI Variable Display","Segoe UI Variable","Microsoft YaHei UI","Segoe UI",sans-serif` | 正文、标题、歌词 |

字号阶梯：mono 标签 8–10px / 正文 12–13px / 小标题 14px / 页标题 22–28px（`letter-spacing:-.05em`）/ 空态大字 30–48px / 播放页 hero 词 42–76px（`clamp(42px,5.3vw,76px)`）。正文行高 ≥1.5，mono 标签行高 1.1–1.8。

**中文字重限制（重要）**：「字重即进度」的连续 wght 300→820 只有西文可变字体（Segoe UI Variable）支持；Microsoft YaHei UI 只有离散字重（Light/Regular/Bold）。落地规则：**西文/数字用连续 wght；中文用 3 档离散映射（Light→Regular→Bold）**，视觉上仍呈「越近当前越重」，无需引入额外字体文件。

### 2.4 边线与圆角

- 粗分隔线 1.5px `--ink`（区块界、console 顶线、表头底线）；发丝线 1px `--line`；行线 1px `--line-soft`。
- 圆角默认 **0**（印刷风）；仅封面 mini、黑胶 mini 等圆形元素例外。虚线边框只用于「添加」类占位按钮。
- 对位十字规线（14px 十字，opacity .5）是全站共享的印刷细节，固定在 frame 右上与主区左下。

### 2.5 动效

| Token | 值 |
|---|---|
| 缓动 | `--ease-out: cubic-bezier(.22,1,.36,1)` |
| 微交互 | 130–180ms（hover 背景、行左缘刻度 scaleY、按钮变色） |
| 入场编排 | 每元素 opacity .5s，`calc(var(--i)*40ms)` 级联延迟，仅首帧一次 |
| 扫描光带 | 1.1s linear 循环（scanbar 渐变扫过） |
| 黑胶 mini | 10s linear 匀速旋转（唯一的持续动画） |
| 字重过渡 | fx-2 下 200ms 平滑；fx-1 下 80ms；fx-0 下跳变无过渡 |

档位 0/1/2 与现有关动效档位对接：**fx-0 下也须好看**——去掉入场编排、扫描光带、黑胶旋转、字重平滑，只留即时状态切换与 hover 变色。`prefers-reduced-motion` 一律压平为 fx-0。

## 3. 全局骨架（激进破格版）

```
┌──────────────────────────────────────────────┐
│ 索引带 44px：AF·04 | ⌂⌕▥♫▶ | ⌕检索 CTRL F | ♫当前曲位 ▶ │
├──────────────────────────────────────────────┤
│ 页头：巨字页名（44–64px）+ mono lede           │
│ 索引行 / 字母尺（按页可选）                     │
│ ┌──────────────────────────┬───────────┐    │
│ │       主工作区             │ 侧注(按页) │    │
│ └──────────────────────────┴───────────┘    │
│ （播放页：无页头，歌词巨字区 + 底部演奏尺）      │
└──────────────────────────────────────────────┘
```

- **索引带 44px**（全页常驻，取代 rail + console 两者）：mono 排印——左 AF 标记，导航 5 项（首页/在线/榜单/本地/播放，active 蓝底白字），右检索入口（聚焦 `Ctrl+F`）+ **当前曲位**（24px 黑胶 mini + 曲名 mono 截断 + play/pause + `m:ss / m:ss`）。当前曲位整块可点进播放页。
- **console 取消**。seek 职责：播放页 = 底部演奏尺（刻度+声纹+段落+播放头同轴，横贯全宽）；其他页不做 seek 条——拖动需求由快捷键（`←→` ±5s）与点击当前曲位进播放页承接。
- **导航栏取消**。`Ctrl+K` 命令面板（功能已有）承接跳页兜底；索引带 5 项覆盖高频跳转。
- 侧注栏按页保留（280–324px），可折叠；播放页右侧队列栏照 r4 保留 324px。
- ≤1150px 折叠侧注与非关键列，≤790px 索引带只留 AF 标记+导航+曲位；**不跳手机导航**。

## 4. 十三页布局职责

| 页 | 版式要点 |
|---|---|
| 首页 | 冷纸目录化 + 巨字页名：每日推荐/最近/本地电台编目为带编号的索引区，无深色 hero、无大数字卡 |
| 本地 | 按 l5 定稿 + 巨字页名：索引带下接巨型「本地。」+ 单一工具栏 + 索引行 + 字母尺 + 目录/架位/作者三视图 + 侧注栏 |
| 播放页 | **巨字剧场本体**：无页头，曲目 mono 头行 → 上一句（细）→ 当前句巨型活字（`clamp(64px,9vw,160px)`，字重即进度，句长自适应缩字）→ 下一句（辅助）→ 底部演奏尺横贯全宽；队列栏 324px 可折叠；4 预设换 token 不换版心 |
| 在线 | 复用目录行语言；音源切换做成 l5 的 views 段钮；批量下载用蓝色主操作 |
| 榜单 | 榜单列表 = 编目表格；下钻沿用目录行 |
| 漫游 | 「为什么是它」做 mono 注记行；个人 FM 卡片区保持冷纸 |
| 电台 | 推荐序列编目；无在线依赖文案 |
| 喜欢 | 目录行 + ♥ 状态蓝标 |
| 最近 | 时间分组 = 登记簿页段（日期做 mono 组头） |
| 下载 | 状态机可视化 = 登记状态列（queued/active/done 用 mono 标签 + 酸橙/蓝/墨区分） |
| 统计 | 周/月/24h/Top 图表用 `--paper-cold` 区 + 墨色数据线，无彩色图表堆 |
| 歌单 | l5 侧注歌单语言放大为主区：表格式歌单 + 目录行 |
| 设置 | 表单沿用 editcard 语言：mono 标签列 + hairline 分组 |

## 5. 与现有架构的衔接

| 现有机制 | 衔接方案 |
|---|---|
| 播放页 4 预设（纸面剧场/黑胶/极简/影院） | 节目单版心为默认预设；其余预设换 token 不换骨架，主题包 JSON 仍只覆盖场景层 token |
| 4 歌词渲染器 | 「字重即进度」落地为 **press 渲染器的新实现**（或第 5 渲染器，实现时看改动面）；其余三渲染器保留 |
| 3 视觉模式 | 声纹模式=演奏尺辅助层（r4 已含）；频谱/环形保留，视觉模式切换行沿用 r4 的 mode-row（町景已于 2026-11-05 移除） |
| 封面取色 | 认领已唱声纹（`--tint`），不染背景 |
| 动效档位 0/1/2 | 见 §2.5 映射表 |
| 桌面歌词/迷你窗 | 共用 mono+冷纸 token，独立小窗各自简化 |

## 6. 验收（继承 docs/25 并扩展到全站）

- 只验 Windows 桌面 1440×900 / 1280×800 / 1024×768。
- 任意页 3 秒内能回答：我在哪、怎么搜、怎么播（无 rail/console 后重点验：索引带当前曲位是否一眼可辨、`Ctrl+K` 兜底是否可发现）。
- 播放页打开 1 秒内，当前句巨字是视线第一落点；任意窗口宽度下巨字不溢出、不换行超过 2 行。
- 蓝色出现处必是当前/选中/主操作；酸橙出现处必是次级状态——抽查全 13 页。
- fx-0 下逐页截屏检查：无入场编排、无光带、字重跳变，版面仍成立。
- 对比度抽查：正文 ≥4.5:1（重点夜间配色与 mono 8px 标签 ≤10px 须 ≥4.5:1，不达标提到 10px）。
- `scripts/mockup-shots.mjs` 捕获桌面状态，告警如实记录。
