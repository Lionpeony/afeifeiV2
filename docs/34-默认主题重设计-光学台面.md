## 2. 四层物理材质体系与性能/门禁红线

### 2.1 四层纵深结构
- **L0 哑光机壳（Chassis）**：`#E6E8EE`（亮）/ `#090A0D`（暗），零模糊，实色阳极铝/深黑钛底座。
- **L1 阴刻凹槽（Well）**：`#D9DCE5`（亮）/ `#050608`（暗），锐利顶内影（≤ 6px）+ 底部 1px 反光边，用于装轨、装盘、装列表。
- **L2 厚玻璃光学件（Lens）**：`--lens-bg` + `--lens-shadow` + `backdrop-filter`，用于顶栏、悬浮播放舱、滑块拇指、按钮、弹窗抽屉。
- **L3 光源与点阵（Emitter）**：`#C82274`（亮）/ `#F25CA2`（暗）主光源 + `#5B7CFA` 夜间冷暮蓝 + `#13151C / #06070A` 深黑点阵屏。

### 2.2 四条防“油腻新拟态”硬红线
1. 绝不使用“左上白外影 + 右下黑外影”的双向柔光凸起；L0 卡片只用单向接触影 + 1px 发丝实边。
2. L1 凹槽内影模糊半径严格 ≤ 6px，要 CNC 折角感而非软枕头。
3. L1 凹槽只用于“装东西的轨与盘”，普通按钮永远是 L2 厚玻璃或干净实体键。
4. 全屏必须同时具备“深黑点阵屏 + 哑光机壳 + 晶莹厚玻璃 + 锐利粉光”四种材质反差。

### 2.3 性能与门禁红线
- 主视口同屏活跃 `backdrop-filter` 块严格 **≤ 3 块**；长列表正文、歌词底与透明桌面歌词窗 **零 `backdrop-filter`**。
- 唯一音频图（`graphOrNull()`）、唯一 rAF（`compositor.ts`）、静止 0 空转；`perf.mjs` 启动恢复 `< 80ms`、滚动 p95 `< 20ms`。
- 严格遵守 `lint.mjs` 规则 5（仅 `tokens.css` 写裸 hex）、规则 7（`var(--z-*)`）、规则 8（`AF_LADDER` 字号）、规则 10（`var(--r-*)` 圆角）、规则 11（`var(--space-*)` 间距）。
- **单文件行数红线（`AGENTS.md §3`）**：每个 `.tsx` / `.ts` / `.css` 文件严格控制在 **≤ 400 行**（将现有 889 行 `glass.css` 按职责拆分为 4 个独立文件）。
