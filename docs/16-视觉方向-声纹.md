# 16 · 视觉方向：声纹（SOUNDPRINT）

> **定位**：与 `14 刻纹` 并列的**第二个母题候选**，不是替代。两者共用同一套纪律，只是"母题"不同：
> 刻纹是**盘**（唱片），声纹是**波**（声音本身）。
> **效果图**：`docs/mockup-19-soundprint.html` · **自评 96/100**

---

## 1. 一句话

**这一屏不是"封面 + 进度条"，是这首歌在你机器上走过的声音。**

声纹来自唯一 analyser（I3），**随播放长出来**——同一首歌听两遍，两次的声纹不一样长、不一样形。这是别家做不到的：它们的"波形"是预先算好的静态图，我们的是**这台机器听到的**。

---

## 2. 为什么换母题（不是换色）

| 问题 | 刻纹（盘） | 声纹（波） |
|---|---|---|
| 第一眼看到什么 | 一个转动的圆盘 | **一整屏起伏的柱状波** |
| 惊艳来源 | 转动 + 金属反光 | **面积**：已播是实心、未播只剩 18% |
| 与机制的绑定 | 播放 = 转 | **播放 = 生长**（更贴 I1 单一时间源） |
| 会不会被误认 | 唱片机（品类明确） | 可能被当成音频编辑器（**必须靠歌词拉回**） |
| 信息量 | 低（只有进度） | 高（能看出段落、副歌在哪、哪里安静） |

**选择声纹的理由**：用户三次否掉"像别人"，而"波形作为界面主体"在消费级播放器里**几乎没人做**（专业音频软件才有）。它同时满足"没见过"和"只有我们能做"。

---

## 3. 设计决定（每条都能验收）

| # | 决定 | 为什么 |
|---|---|---|
| 1 | 声纹占屏高 **55%**，420 根柱，1px 间隙 | 面积即冲击；420 根在 1330 宽下每根约 2px，密度刚好 |
| 2 | **已播 86% 白，未播 18%** | 进度不是一条线，是**面积的转移** |
| 3 | 播放头只有 **1 根**（2px，橙红 + 18px 辉光） | 全屏唯一发光点，眼睛自动跟住 |
| 4 | 段落分隔用 **1px 竖线**（10% 白） | 不加标签，靠密度自己说话 |
| 5 | 字幕区：当前句 30px + 下一句 15px | **防止被当成音频编辑器**——一句人话把品类拉回播放器 |
| 6 | 时间 **92px 等宽**，压在左下 | 第二视觉重心，和声纹形成"横波 + 竖数字"的构图 |
| 7 | 电平表 L/R 各 1px 轨 + 一个数字 | 只留真实可得的量（左右电平、峰值），不编 LUFS |
| 8 | 强调色换 **橙红 `#ff4d2e`** | 比铬黄"热"，更像声波/警示；**全站仍只许一个** |

## 4. 三态（完成度的主要来源）

| 态 | 表现 | 触发 |
|---|---|---|
| **正常** | 声纹 + 已播 + 播放头 | 播放中 |
| **加载中** | 所有柱压到 1px，一道橙红扫描线从左往右刷 | 首帧 / 换源 |
| **无声纹** | 整块留白，一句话："第一次播放时，它会从左往右长出来" | 未播过的曲目 |

**为什么"无声纹"是诚实的**：声纹必须播放过才有。没播过就画一条假波形，等于骗人——这正是 `12 §7` 的"不造假数据"。

## 5. 自评 96 / 100

| 维度 | 权重 | 分 | 扣分理由 |
|---|---|---|---|
| 辨识度 | 25 | **24** | 遮 logo 也认得出"这是播放器里的声纹"（字幕区拉回品类）；扣 1：还没在真实 analyser 数据上验过柱形 |
| 惊艳 | 25 | **24** | 420 根波 + 92px 数字 + 单点辉光，静态也有面积冲击；扣 1：静止时缺"生长"那一下 |
| 完成度 | 20 | **20** | 三态齐 + 点击跳转 + 键盘 + 窄窗（电平表与封面自动隐藏） |
| 品类契合 | 15 | **14** | 字幕区把"音频编辑器"拉回"播放器"；扣 1：只看声纹仍可能误认 |
| 可实施性 | 10 | **9** | analyser 已有；扣 1：420 个 DOM 每 500ms 改 class，需实测低端机 |
| 一致性 | 5 | **5** | 六条刻纹规则全在（零圆角/无阴影/1px/单强调色/等宽/细体） |
| **合计** | 100 | **96** | 达标 |

**迭代记录**：
- v0（草图）· 88：只有波形 + 进度线，被当成音频编辑器 → 加字幕区与 92px 时间
- v1 · 93：三态里"无声纹"是空白，不诚实 → 改成一句"第一次播放时会长出来"
- v2 · **96**：播放头从"整列发光"收成 1 根 + 18px 辉光；强调色从铬黄换橙红（更贴声波，且与刻纹区分）

## 6. 与刻纹的关系（谁来当默认）

| | 刻纹 GROOVES | 声纹 SOUNDPRINT |
|---|---|---|
| 母题 | 盘（转） | 波（长） |
| 适合 | 沉浸、看封面、听专辑 | 分析、跳段、看结构 |
| 默认 | **是** | 否（作为第二种播放样式） |
| 共用 | 同一份 `clock.t`、同一 `LyricDoc`、同一强调色**数量**（各页面只许一处） | 同左 |

**两个母题可以共存**，因为它们守同一套纪律：零圆角、无阴影、1px 线、细体大字、单强调色。这正是 `14 §4` 六条规则的价值——**换母题不换纪律，就不会变成"又一个 App"**。
