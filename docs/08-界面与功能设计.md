## 1. 定位：一句话与三个"不同于市面"

**一句话**：一台**能换看法**的本地优先播放器——同一首歌，四种播放页、四种歌词、任意主题、多音源，切换成本接近零。

市面播放器把"好看"做死在一个模板里。我们的新颖点只有三件，件件可验收：

| # | 不同于市面的点 | 现状 | 判据 |
|---|---|---|---|
| 1 | **换看法**：播放页是五层画布的四种组合，不是四个页面 | ✅ 四预设 + 四歌词渲染器 | 换预设 ≤1 帧；四套肉眼明显不同 |
| 2 | **能力驱动一切**：UI 按音源声明的能力渲染，不写死任何一家 | ✅ 下载/歌单/登录全走能力位 | 加第三家源，`git diff` 里不出现 UI 文件 |
| 3 | **纪律即性能**：单写者、唯一时钟、唯一音频图、七条 lint 门禁 | ✅ verify 全绿 | 劣化 >1.2× → verify 红 |

## 3. 信息架构：窗口与页面地图

### 3.1 三个窗口（都不是"第二份状态"）

| 窗口 | 角色 | 状态流 | 现状 |
|---|---|---|---|
| **主窗** | 全部功能入口 | store 唯一写者 | ✅ |
| **迷你窗** | 桌面小组件 | 只读投影 + 意图转发回主窗（500ms 节流 t） | ✅ M4 `miniWindow.ts` |
| **桌面歌词窗** | 置顶透明条 | 只读投影（文本变了才过 IPC）+ 两种鼠标态 | ✅ M9-1 `82cf764` |

### 3.2 主窗页面结构（五个 tab + 一个叠加层）

```
┌──────────────────────────────────────────────┐
│ 顶栏：logo · [本地] [在线] [歌单] [下载] [播放页] [迷你窗][桌面歌词] │
│ 侧/主区：当前 tab 的页面                       │
│ 底部播放条：封面·标题·进度·控制·音量·fx 入口      │
└──────────────────────────────────────────────┘
   播放页 = tab 之一（stage），不是弹层 —— 与其他页同层切换
   命令面板 = 浮层（Ctrl+K），可触达全部命令，无鼠标可用   ✅
```

**导航规则**：
- tab 切换只挂/卸页面组件，**不许重建 store 或重新解析歌词**（00 §9.2）。
- tab 列表是常量数组，新增页面 = 加一个常量 + 一个视图文件，导航不写 if 链。
- 每个页面组件**不做能力判断**：宿主传什么渲染什么（歌单页收 `canPlaylists` 过滤后的源，✅ M9-5）。

### 3.3 键盘与命令（交互只信两条通道：键盘 + 命令面板）

| 交互 | 行为 | 现状 |
|---|---|---|
| `Ctrl+K` 命令面板 | 全部命令可搜、可键盘执行，结果上限 12 条 | ✅ |
| 空格 | 播放/暂停 | ✅ |
| `←/→` | 退/进 5s | ✅ |
| `↑/↓` | 音量 | ✅ |
| `J/K/L` | 上一首/播放暂停/下一首 | ✅ |
| 键盘纪律 | 文本输入中/录键中/焦点在滑杆 → 页面快捷键静默（00 §9.5） | ✅ |
| `Esc` | 关最上层浮层 → 退播放页 → 无事 | ✅（优先级纯函数） |
| `afeifei://play?id=` | 冷/热启动唤起，白名单只有 play 一个 action | ✅ M5 |
| 长按统一 400ms | 一个功能只有一种触发感受 | ❌ 现无长按功能，加了再立 |

## 4. 播放页：C0–C4 五层画布（本文核心）

播放页的"换看法"= **层的组合**，不是换页面。层序与归属：

| 层 | 内容 | 提供者 | z 序 | 可关 | 现状 |
|---|---|---|---|---|---|
| **C0 壁纸** | 纸纹 / 模糊封面 / 纯色 | 预设 + `--stage-wallpaper-img` | 0 | ✅ | ✅ `.st-wallpaper` |
| **C1 舞台** | 频谱柱 / 粒子等可视化 | 舞台实现（接唯一 analyser） | 1 | ✅ | ✅（不开频谱时纯几何降级，禁假波形） |
| **C2 封面** | 静止 / 旋转 / 视差 | 预设 | 2 | ❌ | ✅ |
| **C3 歌词** | press / karaoke / minimal / theatrical | 歌词渲染器（唯一 `minimalState` 判定） | 3 | ✅ | ✅ 对拍 diff=0（测试钉死） |
| **C4 控件** | 顶栏 / 进度 / 播放条 | 结构层 token（**永不跟封面变色**） | 4 | ❌ | ✅ `--ink-*` 消费处 grep 不到 `--stage-tint` |

### 4.1 四套预设（已实现，参数即验收）

| 预设 | C0 | C1 | C2 | C3 | 成本 | 现状 |
|---|---|---|---|---|---|---|
| **纸面剧场 paper** | 纸纹底 + 噪点 | 无 | 静止 + 细框 | press 印刷 | low | ✅ |
| **黑胶唱机 vinyl** | 深墨 + 同心圆暗纹 | — | 圆形旋转 | minimal | mid | ✅ |
| **极简留白 minimal** | 纯色 | 无 | 大图无框 | karaoke 逐字 | low | ✅ |
| **电影感 cinema** | 封面 blur 48px / scale 1.15 / 亮度 -18% | 频谱 | 视差 ±8px 阻尼 .12 | theatrical | high | ✅ |

外加取色光晕（M9-2 `846d38b`）：`.st-wallpaper::after` 18% `--stage-tint` `color-mix in oklch`，封面一换背景色变、C4 纹丝不动。

### 4.2 切换成本与降档

| 动作 | 上限 | 现状 |
|---|---|---|
| 换预设 | ≤1 帧（卸/挂 C0/C1，不重建 store、不重解码封面） | ✅ |
| 换歌词渲染器 | ≤100ms（只重挂 C3） | ✅ |
| 换主题 | ≤200ms（只覆盖 CSS 变量） | ✅（单主题内明暗切换） |
| **自动降档** | 连续 2s <50fps → 关 C1；仍差 → C0 转静态；>70fps 5s 逐级恢复 | 🔨 未做（现为手动开关），M10 |

## 5. 页面细化（每页四行：布局 / 组件 / 状态 / 密度）

### 5.1 曲库（tab：本地）

- **布局**：头（搜索框 + 导入按钮 + 计数）+ 列表（行式：标题 / 歌手 / 时长 / 状态角标）。
- **组件**：搜索框（增量过滤，p95 由 perf 守）、导入按钮、行点击即播、缺失标"缺失"。
- **状态**：空（"导入文件夹开始"）/ 扫描中（进度 + 可取消）/ 错误（人话，不弹原生框）。
- **密度**：Museeks 式行密度，一屏 ≥20 行。
- ✅ **三视图**（M10-1 `be28a44`）：列表（虚拟化）/ 唱片墙（卡片网格 → 专辑详情）/ 歌手（拼音序列表 → 歌手详情），三视图共享同一份 `getFiltered()`，搜索词全视图生效，切视图不重扫；分组队列独立（点专辑播整张）。
- ✅ **拼音首字母搜索**（M2/M3 即已实现）：21KB 首字母表（`domain/search/pinyin.ts` + `pinyin-data.ts`），原文/连续首字母/字段开头三形态匹配 + 排名；命令面板同索引。**2026-11-03 更正：本文初版凭印象把它标成 🔨，实际早已落地**——状态列必须先 grep 代码再写。

### 5.2 在线（tab：在线）

- **布局**：源选择（能力声明渲染：`canAuth` 才有登录按钮、`canDownload` 才有下载按钮）+ 搜索框 + 结果行。
- **组件**：源下拉、登录按钮（扫码轮询）、结果行（点行即播 / 行内下载）。
- **状态**：搜索中 / 空结果 / 失败冷却（该源灰 15s）/ 未登录能力隐藏（不是点了才报错）。
- **错误**：只显示统一错误码的人话，不出英文堆栈（00 §8）。

### 5.3 歌单（tab：歌单，✅ M9-5 `8de738b`）

- **布局**：左歌单列表 220px + 右曲目列表两栏。
- **组件**：源下拉（只列 `canPlaylists`）、歌单项（名 + 首数）、曲目行（与在线同款）、"加载更多"分页。
- **状态**：未登录（"先登录后才能看歌单"）/ 空歌单 / 加载中。
- **纪律**：只读投影，不做任何写操作；点歌与在线页同一条 `resolveOnlineUrl → player/play` 链路。

### 5.4 下载（tab：下载，✅ M7）

- **布局**：任务列表行（标题 / 进度条 / 速度 / 状态 / 操作）+ 配额用量 + 更改目录。
- **状态**：排队 / 下载中（200ms 节流进度）/ 暂停 / 重试（退避）/ 失败人话 / 已完成（入库即时刷新，不重启）。
- **纪律**：`MAX_ACTIVE=2`、`MAX_TRIES=3`、配额只减不涨；完成走 `recordOp` 单写者。

### 5.5 fx 面板（播放条弹出，✅ M3/M9-4）

- **布局**：6 段 EQ 滑杆 + 频响曲线 canvas（与真实滤波器同公式/频段/Q/采样率）+ 前置增益 + crossfade 档位（关/3s/6s）+ 重置。
- **纪律**：假开关零容忍——每个控件必须有消费方（lint/测试守）。

### 5.6 迷你窗与桌面歌词窗

- 迷你窗：封面 + 标题 + 控件 + 频谱缩略；**只 3 个 preload 方法**（收投影 / 发意图 / 关窗）。
- 歌词窗：白字深描影、悬停浮现工具条（A±/锁定/关闭）、中键锁定 → 穿透、主窗按钮解锁；位置/模式/字号持久化。

## 6. 视觉语言（token 宪法的表现层细则）

- **三层 token**（`tokens.css` 唯一 owner）：
  - `--ink-*` 结构层：文字、边、面。**永不跟封面变**。
  - `--stage-*` 场景层：壁纸、舞台、tint。跟随预设与封面。
  - `--glass-*` 材质层：玻璃 = 四段阴影（外投影 + 强调微光 + 顶部 1px 内高光 + 底部内阴影）+ 双边框，**禁 `backdrop-filter`**。
- **⑥ 玻璃层 `--lg-*`（2026-11-11 新增，首页待播网格专用）**：丙烯板 = 四层 background（板厚/青瓷底偏/主膜/深色不透底）+ `backdrop-filter: url(#lg-lens) blur(4px) saturate(n)` + 亮 1px/暗 1px 成对倒角。
  - **唯一允许 `backdrop-filter` 的材料**，且只给 `.cs-tape` / `.cs-tapes::before`；③ `--glass-*` 的"禁 backdrop-filter"继续有效（浮层后面是正文，不是灯）。
  - 与 ③ 是两种材料，禁止混用：③ 必须 .97 不透明，⑥ 故意半透。
  - 纪律：**结构层不跟封面色**——玻璃的色源是固定光场 `--lg-lamp`，不是 `--cs-tint`。
  - 三死因（改动画/改层级前先读）：祖先或自身 `opacity < 1`、任何 `animation … fill: both|forwards`（含已播完）、祖先链 `filter`。`live-shots` 的 J2 逐层断言，J9 用条纹残留证明玻璃活着（≤20 绿 / 关掉 backdrop ≥90 红）。
- **首页待播卡的焦点环与状态（2026-11-11 变更）**：
  - `focus-visible` 环色 `--live-accent` → **`--live-fg`（墨色）**，`outline-offset` `-2px` → **`2px`（环移到卡外）**。原因：环移到卡外后落在**卡底灯池**上，而灯也是青瓷色系——`#0e8f82` 对灯池实测只有 **2.27:1**（对干净页面才有 3.84:1），环沉进光池；换墨色后对灯池 **10.3:1**、对卡内边 **6.7:1**，深色/纸色一个 token 自动成立。
  - **特异性坑（实测）**：`live.css:55` 的 `.shell.live button:focus-visible`（0,3,1）本来就在生效，且已经是 `offset: 2px` —— 旧写法 `.cs-tape:focus-visible`（0,2,0）从来没赢过它，卡上的环一直是 **accent**，`-2px` 那句是死代码。真正换色必须写 `.shell.live .cs-tape:focus-visible`（0,4,0）。J5a 判据（读 computed outline）守这一条。
  - 代价与遗留（P2-6）：与页内其它焦点环（`.cs-title` / `.cs-all-row` 仍用 accent、`-2px`）语言不统一，待统一到 `--live-fg`。
  - hover 的"边被照亮"实测只有 **1.39:1**（`#b5d3d0` vs `#e6f2f0`）——**它不是状态信号**，只是材质过场，别当可见反馈记在验收里。
  - hover **不动 `backdrop-filter` 的数值**（blur 一变就 180ms × 每帧重算 backdrop），抬升后的"灯照上来"由 `--lg-lift` 内高光负责。
- **裸 hex**：组件层 0（lint 规则 5）；`rgba()/oklch()` 合法。
- **`!important`**：新增文件 0，旧文件只准减少（lint 规则 4）。
- **z-index**：画布 0–4 < 浮层 < 模态 < toast，台账制，禁 9999。
- **动效**：`transform` / `opacity` / `clip-path` / `filter` 白名单；禁逐帧改 `width`；时钟只跟 compositor，渲染器禁自起 rAF。
- 🔨 **M10：主题包导入**——纯数据包（token 全集 + 壁纸），丢目录即换皮，缺 token 键**明确报错不静默回退**（00 §9.3）。
