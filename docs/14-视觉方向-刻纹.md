# 14 · 视觉方向：刻纹（Grooves）

> **为什么有这份文档**：前两版视觉（纸墨 / 流体玻璃）都是"从趋势里挑"，用户判定**"没有自己的风格"**。本文改用另一种方法：**从产品的机制里长视觉**，并用 100 分制自评迭代到 95 以上才输出。
> **结论**：母题 = **黑胶的同心圆沟槽（刻纹）**——它同时是「唱片」「时间」「进度」三件事，不是装饰。
> **效果图**：`docs/mockup-16-grooves-v3.html`（v1 = `mockup-15-grooves.html`，v2 未单独存档，改动见 §3）。
> **另见**：`16-视觉方向-声纹.md`——第二个母题（波 vs 盘），守同一套六条规则，自评 96。

## 1. 参考 11 家：各取一条，都不取整体

| 项目 | 取它哪一条"实现效果" | 不取什么 |
|---|---|---|

| **Mineradio** | 暗底 + 封面做大面积底 | 不取玻璃与光晕 |

| **LX Music** | 桌面歌词独立窗的窄边距 | 后续窗口再用 |
| **YesPlayMusic** | 右半屏整块给封面 | 不取大圆角 |
| **Vynody** | **哑光材质**而非玻璃 | 不取它的 token 色板 |

**空白**：**没有人把"播放器是一台机器"当视觉前提**。这就是我们的位置。

## 2. 评分标准（100 分，可检验）

| 维度 | 权重 | 怎么扣分 |
|---|---|---|
| **辨识度** | 25 | 遮住 logo 能否认出；母题能否扩展到全站（不是一张海报） |
| **惊艳** | 25 | 明暗对比、材质、动势焦点、尺度（有没有"一眼抬头"的地方） |
| **完成度** | 20 | 对齐 / 字距 / 间距 / 边缘 / 空态是否都有决定；有没有"随便放上去"的元素 |
| **品类契合** | 15 | 看一眼知道是音乐播放器，而不是通用 App |
| **可实施性** | 10 | 纯 CSS 能实现、无外部资源、转动与遮罩不掉帧 |
| **一致性** | 5 | 一套规则贯穿，没有拼贴感 |

## 3. 三轮迭代（72.5 → 91 → 96）

### v1（`mockup-15-grooves.html`）· **72.5**

| 维度 | 分 | 扣分点 |
|---|---|---|
| 辨识度 | 18 | 有刻纹，但弧**太淡**（16% 透明度），远看是个"抽象黑胶"，不像产品 |
| 惊艳 | 15 | 封面是纯色圆盘，**没有材质**；没有动势焦点 |
| 完成度 | 16 | 唱臂太简陋；右栏**竖排刻度尺是假数据**（纯装饰）；还有"节目单"残留（`SIDE A · 04`、`ONE RECORD ONE ROOM`） |
| 品类 | 14 | 像"唱片机插画"，不像在播歌 |
| 可实施 | 9.5 | — |
| 一致性 | 5 | 语义残留没清干净 |

**三条致命**：弧看不见、刻度是假的、旧语言（节目单）没清。

### v2（未存档）· **91**

改动（每条对应一个扣分点）：

| 扣分点 | 修法 |
|---|---|
| 弧太淡 | 改 **SVG 2px 弧** + `stroke-dasharray`，已播段用纸白，端点是铬黄方块游标（可读、可精确） |
| 封面无材质 | 盘面叠三层：封面（降饱和 −18%）+ 刻纹（multiply）+ **conic 金属高光**（一处，模拟斜光） |
| 假刻度 | 竖排刻度尺**删掉**，换成**段落结构条**（前奏/主歌A/副歌/主歌B/桥段/尾奏，宽度按真实时长） |
| 节目单残留 | `SIDE A · 04` 只留在中心标签（它是唱片真实的"面/轨"），删 `ONE RECORD ONE ROOM`、删"第 030 场" |
| 字重 | 标题 `300 → 200`，字距从"收紧"改成**拉开 `0.005em`**（精密而非潮流） |

### v3（`mockup-16-grooves-v3.html`）· **96**

| 再加什么 | 为什么值 5 分 |
|---|---|
| **结构条当前段变铬黄 + 呼吸** | 它把"歌词"变成了"剧本"，是全站最独有的一条；也让 chrome 有了唯一的合法落点 |
| **顶栏换成真状态**（`● 正在播放 / 网易云 · FLAC / 队列 3`） | 去掉装饰文字，信息全部真实 |

| 播放暂停时**唱片停转、结构条停呼吸** | 一致性：一个状态只有一个视觉表现 |

## 4. 六条硬规则（这就是"我们自己的风格"）

| # | 规则 | 怎么验 |
|---|---|---|
| 1 | **进度是盘面外圈的一道弧**，不是横线 | 任何页面出现第二条横向进度主视图即违规 |
| 2 | **全站只有一个强调色（铬黄 `#E8FF3A`），面积 <2%，只标"正在发生"** | 截图取色统计；出现在装饰上即违规 |
| 3 | **零圆角、零阴影、只有 1px 刻线**（圆只属于唱片） | CSS 扫 `border-radius` / `box-shadow` |
| 4 | **一切都是"机器面板"**：没有卡片、没有浮起、没有玻璃 | 出现 `backdrop-filter` 或卡片阴影即违规 |
| 5 | **数字全等宽，标题细体拉开字距** | 字重 200–300；数字 `font-variant-numeric: tabular-nums` |
| 6 | **动势只有一个来源：转**。唱盘转、游标转、结构条呼吸 | 不许有位移弹跳、缩放脉冲 |

## 5. 96 分是怎么算的

| 维度 | 权重 | 得分 | 扣分理由 |
|---|---|---|---|
| 辨识度 | 25 | **24** | 遮 logo 也认得出是唱片机；母题可扩展到队列/结构条/窗口。扣 1：还没在真实封面（彩色照片）上验过 |
| 惊艳 | 25 | **24** | 2px 弧 + 铬黄游标 + 金属高光 + 转动的盘；扣 1：静止截图比动起来弱一档 |
| 完成度 | 20 | **19** | 对齐/字距/间距/边缘都有决定；扣 1：唱臂仍是几何近似，不是真唱臂结构 |
| 品类契合 | 15 | **15** | 一眼就是播放器 |
| 可实施性 | 10 | **9** | 纯 CSS + SVG；扣 1：盘面 `repeating-radial-gradient` 在低端机放大尺寸时可能掉帧，需实测 |
| 一致性 | 5 | **5** | 六条规则全部落在这张图上 |
| **合计** | 100 | **96** | 达标（>95） |

**仍扣的 4 分（如实写）**：真实彩色封面下的对比度、动起来的观感、唱臂的机械真实度、低端机性能。

## 6. 六种播放样式（同一规则，六种信息重心）

> 效果图：`docs/mockup-17-styles.html`（顶部方块或键盘 1–6 切换，六套共享同一份时间源）

**不是六套皮肤，是六种"这屏该以什么为主"**。它们全部遵守 §4 的六条规则，所以换来换去仍然是同一个播放器。

| # | 样式 | 主角 | 一句话 | 自评 | 风险 |
|---|---|---|---|---|---|
| 01 | **GROOVES 唱片** | 盘面 + 弧进度 | 播放的本质是转 | **96** | 已定稿 |
| 02 | **SCRIPT 剧本** | 段落条 + 当前句 | 把歌词当剧本读 | 92 | 左栏章节与歌词信息重复 |
| 03 | **METER 仪表** | 波形 + 数据列 | 像一台机架设备 | 90 | **LUFS/峰值/动态我们没有**（`11 §3.5` 明确不做响度分析）→ 只能显示采样率/位深/已播/段落，没有的留 `—` |
| 04 | **CINEMA 影院** | 全屏封面 | 一张图撑满屏幕 | 93 | 最容易"像所有播放器" |
| 05 | **POSTER 海报** | 巨型标题 | 一页唱片内页 | 94 | 信息量最少，不适合日常操作 |
| 06 | **RIBBON 长卷** | 整首歌的时间轴 | 把歌摊开来看 | 91 | 学习成本最高 |

**默认与存储**：默认 `GROOVES`；用户切换写 KV `stage-style`（键名合规，`^[a-z][a-z0-9-]{0,31}$`），三窗共用同一值。

**实现成本**：一套 ≈ 2.5 天（含窄窗与空态）。**建议先做 01/04/06 三套**（差异最大、覆盖三种场景：操作 / 观感 / 分析），02/03/05 等前三个稳了再加。

**一条硬约束**：六套共用 `clock.t` 与同一份 `LyricDoc`，**不许任何一套自己算行**——否则六个视图的"现在唱到哪句"会分叉，这正是 `00` 的 I1 要消灭的东西。
