# 13 · 全站重设计蓝图

> **⚠️ 视觉方向范围更新（2026-11-04）**：播放页经用户确认改为 **Type Is Time · 歌词即时间**；播放页的主签名由真实歌词时钟驱动，见 `docs/00 §9.2`。本改动仅覆盖播放页；外壳和其他页面仍按各自已实现视觉与功能蓝图处理，不把旧 Grooves 播放页稿当作实现依据。
> **功能布局仍有效**：播放页为主场、导航收口、console 浮动；播放页首屏以曲目身份 + 实时歌词字形 + 真实队列为核心，底部播放控制仍由全局 console 提供。

> **授权**：用户原话——**"可以全部重新设计，所有页，所有功能排版。"**
> **范围**：外层壳 + 10 个页面 + 2 个小窗，**全部重排**。功能清单不变（功能归 `08`），产品方向归 `12`，本文只管"每一页长什么样、由哪些零件拼、按什么顺序施工"。
> **不动**：五环架构、I1–I5、lint 七条、token 三层结构、能力声明表。**重设计的是表现层，不是骨架。**
> **作废**：`09-样式还原-唱片节目单.md`（纸墨时代的排版规格）与 `10-改版进度-v11.md` 的页面映射，**整体作废**，不再作为施工依据；`docs/assets/*.png` 全部重拍。

## 1. 一句话

**打开就是暗场，封面是唯一光源；字是纸色的，光是封面给的。**

> **效果图**：`docs/mockup-13-暗房.html`（单文件、双击即开、零依赖）。可点左栏切页、点相纸封面进沉浸态、拖 console 进度条；封面是 CSS 渐变占位，真实版本是解码后的图。与本文的 1 处偏差：播放页不再单独给 HUD，seek 只在浮动 console 里。

纸墨时代我们做的是"唱片内页"，现在做的是**开演前的黑场**——同一套印刷纪律（1px 线、等宽数字、零圆角、朱砂只标正在发生），换一个底，张力翻倍。

## 2. 设计系统（值表，不是形容词）

### 2.1 色

| token | 值 | 用在哪 |
|---|---|---|
| `--bg` | `#0a0b0d` | 全局底（略暖近黑，纯黑显塑料） |
| `--surface` | `#121316` | 卡片/列表底（抬一层） |
| `--surface-2` | `#191b1f` | 浮层/弹窗底 |
| `--fg` | `#f3f1ea` | 主文字（**原纸色变成字色**） |
| `--fg-dim` | `rgba(243,241,234,.55)` | 次文字（暗底必须降到 55%，否则发灰） |
| `--fg-mute` | `rgba(243,241,234,.35)` | 三级信息/占位 |
| `--accent` | `#e0492f` | 朱砂提亮一档（原 #d8341c 暗底发乌） |
| `--accent-ink` | `#0a0b0d` | 朱砂上的字 |
| `--brass` | `#c9a35c` | 徽章/票据 |
| `--line` | `rgba(243,241,234,.22)` | 分区线（比纸底更细更暗） |
| `--line-soft` | `rgba(243,241,234,.10)` | 行分隔 |
| `--glow-1` | 封面主色 40% | 环境光主色（**运行时写入**） |
| `--glow-2` | 封面次色 20% | 环境光副色 |

**规则**：朱砂只标"正在发生"（正在播放 / 当前歌词 / 进度头 / 主操作）；其余全是纸色文字。**暗底上朱砂面积不得超过屏 3%**。

### 2.2 光（这次新增的层，也是惊艳的来源）

```
z 0  环境光层（固定，不随页面切换）：两张超大径向渐变，--glow-1 40% + --glow-2 20%
z 1  噪点层（soft-light，opacity .025）
z 2  内容
z 5  console（半透明黑 + 1px 亮边）
z 60 浮动层（菜单/弹窗）
```

- 环境光**每页都有**，不是播放页专属；切歌时 600ms 过渡。
- 无封面时 `--glow-1/2` 回落为 `transparent`（**不许回落到朱砂**——`presets.ts` 已经踩过"粉墙"这个坑）。
- 光只写 `background` / `opacity`，不写 blur（大面 `backdrop-filter` 掉帧）。

### 2.3 字

| 档 | 字号 | 字重 | 用在哪 |
|---|---|---|---|
| display | 96px / 1.02 | 400（衬线） | 播放页曲名、报告页大数字 |
| h1 | 72px | 500 | 页面主标题（首页/本地…） |
| h2 | 33px | 600 | 分区标题 |
| body | 15px | 400 | 正文 |
| small | 13px | 400 | 列表副行 |
| mono | 11px / .16em | 400 | 编号、时长、英文小标 |

**中文衬线必须自托管一个标题字重**（子集化 1.5–3MB，OFL 许可登记 `02`）。这是"第一眼"的核心，纸墨时代砍错了，这次补回。
**暗底行高 +10%**（暗底小字更难读）：正文 1.55 → 1.7。

### 2.4 尺寸

| 项 | 值 | 说明 |
|---|---|---|
| 外壳 | 左导航 72px（纯图标，hover 出文字） | 比现在 96px 再收 24px，主区更宽 |
| 顶栏 | 44px "票根头"（品牌点 + 当前页 + 状态） | 去掉 38px 那套三件套，减少一条横线 |
| 内容边距 | 40 / 32 | 比现在 32/30 更松，暗底需要呼吸 |
| 列表行 | **46px**（现在 42） | 暗底 + 密度降一档 |
| 封面档 | 40 / 160 / 360 / 640 | 列表 / 行内 / 播放页 / 首屏 |
| console | 88px，**浮动**（不占网格行） | 内容区因此多 16px，且滚动时 console 浮在上面 |
| 圆角 | 0（例外：999 胶囊、50% 黑胶） | 保留印刷纪律 |

### 2.5 动效三条曲线（全部只用 transform / opacity）

| 名字 | 时长 / 曲线 | 用在哪 |
|---|---|---|
| **换幕** | 120ms `ease-out` | 切页、切歌：纸色遮罩一闪（`opacity 0→.9→0`） |
| **落版** | 240ms `cubic-bezier(.22,1,.36,1)` | 元素入场：`translateY(10px)+blur(4px)→0`，行间 stagger 40ms |
| **换台** | 520ms 同上 | 封面 → 沉浸播放页（FLIP：封面位置/尺寸插值） |

**`fx-0`（动效关）下三条全部消失，但布局不许跳。**

## 3. 信息架构：播放页是主场，其他是后台

```
┌──────────────────────────────────────────────────────┐
│ ● afeifei   正在播放            3 首 · 网易云   ─ □ ✕ │ 44px 票根头
├────┬─────────────────────────────────────────────────┤
│ ▤  │                                                 │
│ ▤  │        内容区（全高，无内层滚动条除非列表）      │
│ ▤  │                                                 │
│ ▤  │                                                 │
│    │                                                 │
│ ♥  │                                                 │
│ ◷  │                                                 │
│ ⚙  │                                                 │
├────┴─────────────────────────────────────────────────┤
│ ▓▓▓ 入场券 · 封面 · 曲名 · 走带 · 细线 seek · 工具   │ 88px 浮动 console
└──────────────────────────────────────────────────────┘
```

**三条结构决策**：

1. **落地页 = 播放页**（有上次播放）或 **首页**（无）。播放页不再是"点 console 才进的第二屏"——它是前台，其他页是后台。
2. **导航 72px 纯图标**，hover 才出中文；底部固定三枚（红心 / 最近 / 设置）。中间四项：首页 / 在线 / 电台 / 漫游 / 本地 / 下载 → 收成"首页 / 在线 / 本地 / 下载"四个（电台与漫游并入首页的第二屏，因为它们本质是"推荐"的两种摆法）。
   > 页面数从 10 → 8，减少"每个都半成品"的感觉。
3. **console 浮动**：`position: sticky; bottom: 0`，背景 `rgba(10,11,13,.92)` + 顶部 1px 亮边。滚动时内容从它下面穿过（有纵深），不占网格行。

### 4.1 播放页（主场 · 默认落地）

```

MIDNIGHT CITY · M83 · ALBUM / SOURCE                 QUEUE 04/18

Wait in the car,                    ┌──── 接下来 ────────────┐
waiting for the ride                 │ 019  Wait              │

    字形进度来自真实歌词时钟)         └────────────────────────┘

歌词分层：已唱可读 / 当前字高对比并放大 / 未唱柔化但不隐藏
```

- **主签名**：正在唱的字/词成为页面最大视觉对象，逐字时间由 `LyricDoc.words` 驱动；没有词时间时安静回到行级高亮。

- **诚实状态**：无歌词显示纯音乐说明；无逐字时间不伪造字级动画；无 analyser 信号就不显示动态谱线。封面只作曲目身份辅助，不再压过歌词主视觉。

## 7. 验收（每页三条，不许"看着还行"）

1. **3 秒盲测**：5 个人看截图，问"这是听歌的吗"（5/5）+ "想点一下吗"（≥4/5）。
2. **尺寸断言**：960×620 下无横向滚动、无按钮竖排、文字不截断（`page-shots.mjs` 两档）。
3. **一致性断言**：朱砂面积 ≤3%、字号档位只允许表内 6 档、圆角只允许 0/999/50%（脚本扫 CSS）。
