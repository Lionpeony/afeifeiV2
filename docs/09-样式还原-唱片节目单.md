## 6. 我的优化点（不复刻清单，理由写死）

| # | 旧做法 | 决定 | 理由 |
|---|---|---|---|
| 1 | 186 个 `!important`、五层 CSS 覆盖叠罗汉 | ❌ | v2 lint 规则 4 守 0；旧仓自己都把这当历史债（ref/20 §5） |
| 2 | `--rs-*`/`--pr-*` 双轨 token | ❌ | ref/20 §9 已判定单 owner；v2 三层 token 已是收敛后的形态 |
| 3 | 首页"一屏塞满"整页 | ❌ | v2 无该功能位；其排版气质并入曲库页头 |
| 4 | 演出模式 L3、电台 roam 等无对应功能的页 | ❌ | 功能不存在就不还原壳（00 §1.2：YAGNI） |
| 5 | 纸纹不可关 | 🔨 改进 | 旧要求可关但从未做；随外观面板补开关（存 audio/setting 域） |
| 6 | 夜间主题 `#171613` 暗纸面 | 🔨 保留价值 | 先立 `[data-theme]` 通道再给两套值，一份 CSS 通吃（ref/20 §9 非协商项） |
| 7 | mono 标签滥用到正文 | 🔨 收敛 | 只用于元数据/注（10px 档），正文保持 sans——可读性优先 |
| 8 | 播放头 pulse 动画 | 🔨 保留 | 朱砂 pulse 2.4s 是"正在播放"的法定红用途，加 `prefers-reduced-motion` 豁免（旧仓已做，照抄） |
