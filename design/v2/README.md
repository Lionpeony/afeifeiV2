## 迁入时修的三处

1. **相对路径**：原来引用 `../online-covers/`，迁到 `design/v2/` 后指向不存在的目录 → 全部改成 `online-covers/`（a2 五处、b2 四处）
2. **依赖漏带**：`core.css` 不带的话两页会是纯白（变量与基础排版都在里面）
3. **截图时机**：两页都有入场/换句动画，脚本原等 360ms 会截到"句与句之间的空档" → 改成 1600ms
