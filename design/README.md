# design/ · 设计稿

本目录放**可交互的设计稿 HTML**（单文件、零依赖、双击即开）。不是产品代码，不参与 `npm run verify`。

## 出图

```bash
npx electron scripts/mockup-shots.mjs design/01-grooves.html
# → docs/assets/mockups/01-grooves.png
```

- **单页稿**（没有 `#switch`）：直接截一张，文件名 = html 名。
- **多页稿**（带 `#switch` 和 `data-v`）：按 `VIEWS=g,s,w,...` 逐页切、逐页截，每次切换会**回读 `.view.on` 校验**，并等两帧 —— 不等就会截到上一页（踩过）。

## 评分口径

用 `docs/15-交付门槛-95分.md` §2.1 的专业标准：创意 25 / 视觉 25 / 功能 20 / 执行 20 / 一致 10。
**95 分 = A+ 区间**，含义是"行业顶尖、可作标杆"。

## 规矩

1. 改了稿必须重出图，**看截图再打分**——没截图不许评分（`docs/15` §4.1）。
2. 分数只许因为"扣分点被修掉"而上涨。
3. 历史稿不删，改名不改内容，避免"昨天那张找不到了"。
