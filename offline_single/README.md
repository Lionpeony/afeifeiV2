# AFEIFEI 播放器 · 单文件离线版（双击即开）

## 打开方式
解压后**双击 index.html**，任何现代浏览器直接打开。
- 无需登录、无需联网（联网时自动加载主题字体，断网用系统字体，不影响使用）；
- 这就是**在线原型的原版**，逻辑与样式零改动，只做了自包含化。

## 上一版打不开的原因
上一包把 React/Babel 放在 `vendor/` 子目录、CSS 在 `css/` 子目录——如果 zip 没解压直接双击、或解压后单独移动了 index.html，相对路径全部失效就会白屏。本版已把 **JSX + React + Babel + 8 个 CSS 全部内联进 index.html 一个文件**，不存在任何相对路径依赖，index.html 放哪都能开。

## 已验证（2026-11-17 实测）
- 无头 Chromium 以 file:// 协议真实打开：React 组件成功挂载，渲染出「入场登记」页；
- DOM 转储 4.4MB，关键界面文本（发现/每日推荐/歌单）全部在渲染结果中；
- 1440×900 截图视觉确认：门票卡片、双音源登录卡、免责声明均正常显示；
- 22 个 JSX 块 @babel/standalone 转译 22/22 通过。

## 封面说明（v2 变更）
- 原版 8 张封面存放在妙搭平台私有存储，需要登录态才能取到——离线/免登录场景必然取不到（这是平台架构决定的，原图无法提取）；
- 本版按原版程序化插画风格重画了 8 张原创矢量封面（渐变底 + 吉他/拨片/星月/音符/胶带元素，各专辑专属配色），以 data URI 内嵌进 HTML，彻底零外部依赖。
