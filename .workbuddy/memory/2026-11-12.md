## 2026-11-12 首页切歌转场（列表卡飞进大图 / 旧封面缩回）
- 做法：**共享元素转场 = body 上的 fixed 副本**（`spawnFly`）。绕开两件事：`.cs-stage` 的 `overflow:hidden` 会裁掉放大中的封面；`key={lead.sourceId}` 换歌即重挂，容器内没有中间态。
- **宽高逐帧补间，不用 `transform: scale()`**：卡面正方形 / 大图竖矩形，统一 scale 会拉变形，`object-fit:cover` 只在盒子真变尺寸时才裁得对。
- **叠放靠 DOM 顺序**（两份副本同 z-index 50，全局层序白名单只有 40/50/60）：旧的先建垫底、新的后建压上，否则交叉点处旧封面盖住"飞进来"。
- **落位必须"真封面当帧不透明"**（`.cs-stage.cs-landed .cs-cover{animation:1ms}`）：副本淡出 + 真图淡入时，两层同图 alpha 之和 < 1（0.5 叠 0.5 仍透 25% 底），会闪底。
- 列表整排左移：只动 `.cs-tape`（`translateX(+step)→0`），**不动 li**（li 是光场 position-anchor 宿主，动它每帧重算 5 张卡 backdrop）。
- 触发范围（用户定）：手动点卡 + 自动播完；上一首/随机无源坐标 → 回落淡入，不编造出发点。
- **取证坑**：`capturePage` 有 300–800ms 延迟，380ms 的动画永远抓不到中段；`pause()+currentTime` 定格会让 capturePage 卡死（实测 7 分半不返回）。正解 = 临时把 FLY_MS 放大到 2000 + `SWAP_SHOTS=1`，拍完改回。
- **CSP 又踩一次**：新建 `<style>` 的 `st.sheet` 是 null（style-src 'self'），插规则只能往已有 `document.styleSheets` 里 `insertRule`。
- 判据 T1–T5 进 live-shots（两份副本 / 尺寸一大一小 / 新封面在 DOM 最后 / flying+opacity0 / 落位清零）；J1–J10 同时全绿，669 单测全过。
