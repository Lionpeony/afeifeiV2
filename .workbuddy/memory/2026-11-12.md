
## 2026-11-12 液态玻璃待播卡上线（1b230e4 / a69da3c / c677e65 / 5b73ec5 / 7deeef1）
- 结论：**Electron 33 / Chromium 130 里 backdrop-filter: url(#lens) 的 SVG 位移折射真的能用**（探针 design-demos/glass-probe/probe.png），之前"Chromium 不支持位移"的判断是错的；11/10 失败的是 liquid-glass-react 的架构（自己给祖先加 filter）。
- 落地「架上灯」：光场 ::before + CSS anchor positioning（position-anchor/anchor-size 定位，误差 0.00px，字号扰动仍 0.00）代替手算常量；玻璃膜 rgba(246,250,249,.62) + blur 4px + saturate 1.6 + scale 10 倒角透镜。
- **三死因（实测）**：祖先/自身 opacity<1、任何 animation…fill:both（含已播完）。修复：`.cs-enter .cs-feed` 与 `.live-bleed` 的 both → backwards，卡片入场挪到 `.cs-tape` 自身。
- 判据 J1–J10 进 live-shots；J9 用条纹板扫信息带残留（活 7–13 / 关掉 backdrop 93–95）。
- 判据坑：本页 CSP style-src 'self' 静默拒绝注入 <style>（假绿）；插入条纹板后 Chromium 不重拍 backdrop 快照，必须显式推 style 失效并读两遍。
